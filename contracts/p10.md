# P10 批次 4：研究能力 P1

来源：[调研报告](../doc/reviews/2026-11-05-gap-research.md) 第二节 B7–B15、第四节批次 4。沿用 P2 / P8 统计约定：统计为后台任务，结果为 `StatResult`，计算在 engine，不访问数据库；能回到例句的行都给 `search_query`。

## 一 文本指标（B7）

`POST /stats/text_metrics`：`{scope, metrics?: [...], group_by?: "<元数据字段>", sttr_window: 1000}` → `Job`。

- 每篇文档一行：文档标题、语言、词数（不含标点）、句数、TTR、STTR（每 `sttr_window` 词一段，最后不足一段的不计）、MTLD（McCarthy & Jarvis 2010，阈值 0.72，双向平均）、词汇密度（实词 / 词数，实词 = UPOS NOUN、PROPN、VERB、ADJ、ADV；jieba 标签按前缀映射 n、v、a、d）、平均句长（词）、平均依存距离（有依存的句子，|head − i| 均值，不含根；无依存为 null）、英文另有 Flesch Reading Ease 与 Flesch-Kincaid Grade（音节按元音组启发式计数）。
- `group_by` 时另返回分组汇总（`totals.groups: [{value, documents, mean, sd}]` 每个指标），文档无该字段归"（无）"。
- 词数 < 100 的文档 STTR、MTLD 为 null（写入 `totals.notes`）。
- 列标题悬停显示公式；方法附录（P8）收录这些指标的公式与文献。

## 二 词汇等级画像（B8）

- 词表：内置 NGSL 1.2（CC BY-SA 4.0，署名写入元数据与方法附录）；用户可上传词表（CSV / TXT：每行 `词,等级`，等级为字符串，如 HSK 1–9、AWL、自定义）。HSK、AWL 不内置（许可不明），引导用户自行上传。
- 迁移 `0012`：`vocab_lists(id, project_id null=内置, name, language, levels jsonb [按顺序的等级名], source, license, created_by, created_at)`、`vocab_entries(list_id, form, level, PRIMARY KEY(list_id, form))`。英文按小写词元匹配，中文按词形匹配。
- 接口：`GET /projects/{id}/vocab-lists`（含内置）、`POST /projects/{id}/vocab-lists`（multipart，editor 起）、`DELETE /vocab-lists/{id}`。
- `POST /stats/vocab_profile`：`{scope, list_id, by: "corpus" | "document" | "<元数据字段>"}` → 每个等级的词次、词种、词次覆盖率 %，另加"表外"；`by=document` 每篇一行各等级覆盖率。等级行的 `search_query` 为该等级词的选项式（> 200 个词时为 null）。

## 三 整洁数据导出（B14）

`POST /stats/tidy_export`：`{scope, queries?: [string] (≤ 10), metrics?: bool, format: csv | xlsx}` → `Job`（kind = export）。

- 每篇文档一行：document_id、标题、语言、全部元数据字段（每字段一列）、词数、句数；每个查询两列 `q{n}_hits`、`q{n}_pm`（每百万词）；`metrics=true` 时附第一节的文档指标。表头第一行为列名（英文蛇形命名，便于 R / pandas），第二个 sheet（xlsx）或同名 `.codebook.csv`（csv 时打包为 zip）为列说明：列名、含义、单位、查询式。
- 统计页与检索页"导出整洁数据"入口。

## 四 多项对比与历时（B11）

`POST /stats/compare`：`{items: [{label, scope, query}] (2–10), by?: "<元数据字段>" | null, test?: "none" | "mann_whitney" | "spearman"}` → `Job`。

- 不带 `by`：每项一行：标签、范围、命中数、词数、每百万词、文档数、文档频率 %；两项时附 LL 与 log ratio（同关键词公式）。
- 带 `by`（如年份、体裁）：行为字段值，列为各项的每百万词（文档合并计），可画折线 / 分组柱图。
- 检验按文档：每篇文档的每百万词为一个观测。`mann_whitney`：恰两项时比较两组文档（U、z、p、效应量 r）；`spearman`：`by` 为数值字段时每项与该字段的秩相关（ρ、p、n）。数值实现与 SciPy 一致（测试中可用 SciPy 作参考，运行时不引入 SciPy 依赖若当前未依赖；若已有则直接用）。
- 每行可回到检索（该项的查询与范围，`by` 行加字段筛选）。
- 分布（P2 distribution）保留；统计页新增"对比"方法。

## 五 Word Sketch（B10）

`POST /stats/word_sketch`：`{scope, lemma, pos?: "NOUN"|"VERB"|"ADJ"|..., layers?, min_freq: 2, top: 25}`；`POST /stats/sketch_diff`：`{scope, lemma_a, lemma_b, pos?, min_freq: 2, top: 25}` → `Job`。

- 关系按 UD 依存从节点词元出发：主语（nsubj、nsubj:pass 的从属词，节点为 head）、宾语（obj、iobj）、被修饰 / 修饰（amod、advmod、nmod、compound 两个方向分别成栏）、并列（conj）、介词短语（obl / nmod 的 case 词 + 名词，栏名如"with + N"）、作主语的谓词（节点为 nsubj 从属词时的 head）。每栏：搭配词元、共现频次、logDice（按该关系计）。`totals.relations` 列出栏名。
- 依存来源：英文用系统层（导入时 Stanza 已有依存）；中文需要依存标注层（`layers.dep` 指定，或默认取该语料最新的已完成依存预标层）；没有依存时 422 `NO_DEPENDENCIES`"该语料没有依存标注，请先在标注页建依存层"。
- Sketch diff：两个词元在各关系栏的共同与独有搭配，列 `freq_a`、`freq_b`、`logdice_a`、`logdice_b`、`diff`（logDice 差），按 diff 排序分出"偏 A / 共同 / 偏 B"。
- 行回到检索：`{lemma=节点} ... {lemma=搭配}` 带 `{dep=…}` 约束的等价查询；无法等价表达时 null。
- 统计页新增"词汇画像（Word Sketch）"与"近义词对比"，结果按栏分块显示。

## 六 语料语义检索（B12）

- 迁移 `0011`：`sentence_embeddings(sentence_id bigint pk → sentences(id) ON DELETE CASCADE, corpus_id uuid, embedding vector(<维度同知识库向量>))`，HNSW 索引（cosine）；`corpora.semantic: jsonb default '{}'`（`{status: none|building|ready|failed, sentences, model, built_at, error}`）。
- `POST /corpora/{id}/semantic-index`（editor 起；内置语料仅管理员）→ `Job`（kind = embed_corpus，长任务道）。句数上限 `SEMANTIC_MAX_SENTENCES`（默认 300000），超过 422 `TOO_LARGE`。复用 `engine/kb/embed.py`（本地 MiniLM 或远程），按 512 句一批，进度按句；可取消。语料重建索引（文档增删）后语义索引标记过期（`status=stale`），提示重建。
- `POST /search/semantic`：`{scope, text (≤ 500 字), top: 50}` → `{items: [Hit + score]}`：按余弦相似度取最相近的句子（范围筛选在 SQL 中），命中范围为整句。结果可钉证据、看上下文。
- 检索页"语义"模式开关（与查询式检索并列）：输入一句话，返回相似句列表与相似度；语义索引未建时显示"建语义索引"按钮（有权限时）与句数、预计时间。

## 七 导入扩展与去重（B13）

- 新格式：PDF（复用 `engine/kb` 的文字层解析，每个 PDF 一篇文档，元数据带页数；无文字层的 PDF 失败"PDF 没有文字层（扫描件），暂不支持 OCR"）；XLSX（同 CSV 列映射，取第一个工作表或指定工作表）；JSONL（每行一个对象，字段映射同 CSV：正文字段、标题字段、元数据字段）。
- 去重：导入时对文档正文做规范化（去首尾空白、合并空白、NFKC）后哈希，同一语料内已有相同哈希的文档跳过；任务结果写 `skipped_duplicates` 与前 20 个重复文件或行号。`documents.content_hash` 列在迁移 `0011` 中加入（含索引），存量文档在迁移中补算（大语料迁移时间写入部署手册）。
- 上传对话框：新格式的映射界面复用 CSV 的；完成后显示"跳过重复 N 篇"。

## 八 更多语种（B9）

- 支持语言：zh、en、ja、fr、de、es、ru。ja、fr、de、es、ru 用 Stanza（tokenize、mwt（fr、de、es）、pos、lemma、depparse），标签集 UPOS + UD 依存；模型在首次需要时下载到 stanza 卷（进度消息"下载 fr 模型"），下载失败给出明确错误。
- 内存：worker 同时最多加载 `STANZA_MAX_PIPELINES`（默认 2）个语言的管线，按最近使用淘汰。
- P9 的语言限制改为：不在上述七种中的语言才 422 / 失败；自动识别：汉字为主 → zh；假名占比 > 5% → ja；西里尔为主 → ru；拉丁文本按各语言高频功能词（每种 30 个）占比取最高者，最高 < 3%（词数 ≥ 200）时失败"未识别语言，请指定"；中文文本夹英文术语仍判 zh。
- 检索：ja 的字串查询与 zh 相同（可跨分词边界）；其他语言按词。词性短标签 `/n` 等只对 zh（jieba）有效，其他语言用 UPOS。
- 统计、标注（词性、依存预标与校对）、KWIC 对所有支持语言可用；术语抽取的词性模式目前只有 zh / en，其他语言在术语抽取处禁用并说明。
- 上传与新建语料的语言下拉增加五种语言。

- 文本指标：与独立参考实现（tests/golden）一致（TTR、STTR、MTLD、词汇密度、平均依存距离、Flesch）；分组均值与标准差正确。
- 词汇画像：NGSL 覆盖率与参考实现一致；上传 HSK 词表后中文作文的等级分布正确；表外词可回到检索。

- 对比：两项 LL 与关键词公式一致；Mann-Whitney、Spearman 与 SciPy 一致（误差 < 1e-9）。
- Word Sketch：UD 英文 EWT 上 `make` 的宾语栏含 decision 等；中文无依存层时 422；有层时可用；sketch diff 分栏正确。
- 语义：Tatoeba 中英第 1 批的中文侧建索引（句数在上限内）、可取消；"我喜欢读书"返回语义相近句；范围筛选生效；删文档后标记过期。

- 语种：法语、德语、西语、俄语、日语各一份真实 TXT 导入后可检索、可统计、KWIC 正确；自动识别正确；中文夹英文术语仍判 zh；同时导入三种语言时内存受 `STANZA_MAX_PIPELINES` 控制（记录峰值）。

- 权限矩阵补全部新接口；现有测试不回归。
