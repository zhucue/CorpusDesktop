# P8 批次 2：研究能力 P0

来源：[调研报告](../doc/reviews/2026-11-05-gap-research.md) 第二节 B1–B6、第四节批次 2。补齐论文最常用的频次表、离散度、效应量与译法统计，以及检索结果抽样编码和方法附录。沿用 P2 统计约定：统计为后台任务（kind = stats），结果为 `StatResult`，每行可回到检索；计算在 `engine/stats.py`，不访问数据库。

## 一 命中频次分解（B1）

`POST /stats/breakdown`：`{scope, query, by, top: 200, min_freq: 1, layers?}` → `Job`。

| by | 含义 |
| --- | --- |
| `word` / `lemma` / `pos` | 命中本身（多词命中以空格连接各词的词形 / 词元 / 词性） |
| `left1` / `right1` | 命中左侧 / 右侧第一个词的词形（句首、句末记为"（句首）""（句末）"） |
| `meta:<字段>` | 命中所在文档的元数据字段值（无该字段的记为"（无）"） |

- 列：项、命中数、占比 %（占全部命中）、每百万词（以范围词数为分母）。`totals` 增加 `hits`（全部命中数）。
- 回到例句：`word` 行为 `"w1" "w2"…`（精确词形序列），`lemma` 行为 `{lemma=…}` 序列，`pos` 行为 `/tag` 序列，`left1` / `right1` 行为 `"左词" 原查询` / `原查询 "右词"`；原查询带同句条件时条件一并保留；`meta` 行同 distribution，用 `search_scope` 临时筛选。无法等价表达的行 `search_query: null`。
- 计数与检索一致：全部命中数等于同一查询在同一范围的 `counts.hits`。
- 检索页结果栏加"分解"下拉（按词形 / 词元 / 词性 / 左一词 / 右一词 / 元数据字段），选中后以当前查询与范围发起统计并跳到统计页结果。

## 二 离散度（B3）

`POST /stats/frequency` 增加 `parts: "document" | "segments" | "field:<字段>"`（默认 `document`）与 `dispersion: bool`（默认 true）。

- 部分（part）：`document` 每篇文档一部分；`segments` 按范围内语料顺序等分 10 段（按词数）；`field:<字段>` 每个字段值一部分（无该字段的文档不计入）。
- 新增列：`range`（出现的部分数）、`range_pct`（占部分总数 %）、`dp`（Gries DP）、`dp_norm`（DPnorm = DP / (1 − min sᵢ)）、`juilland_d`（Juilland D，用各部分相对频率 pᵢ = fᵢ / 部分词数，D = 1 − CV / √(n − 1)）。部分数 < 2 时这些列为 null，`totals.parts` 给出部分数。
- 公式：sᵢ = 部分词数 / 范围词数；vᵢ = fᵢ / f；DP = ½ Σ|vᵢ − sᵢ|。0 表示均匀，越大越集中。
- `doc_freq` 列保留（`parts=document` 时等于 `range`）。
- 统计页频次方法显示"部分"选择与上述列；列标题悬停显示公式一句话。

## 三 效应量与对比（B4）

关键词 `POST /stats/keywords` 增加：

- 列：`pct_diff`（%DIFF = (目标每百万 − 参照每百万) / 参照每百万 × 100，参照为 0 时用 0.5 次平滑并标注）、`odds_ratio`、`log_ratio_ci_low` / `log_ratio_ci_high`（95% 置信区间，log₂ 尺度，SE = √(1/a + 1/b)，0 次用 0.5 平滑）、`bonferroni`（按检验的词型数校正后的显著性标记，阈值同现有 0.05 / 0.01 / 0.001）。
- 参数：`direction: "positive" | "negative" | "both"`（默认 positive，即现行为；negative 为参照显著多于目标的词）；`items?: string[]`（≤ 50）只返回这些词的行，忽略 `min_freq` 与 `direction`，用于单项两库对比；`measure` 增加 `pct_diff`、`odds_ratio` 可选排序。

搭配 `POST /stats/collocations` 的 `measures` 增加 `mi3`、`delta_p`（ΔP，两个方向：`delta_p_node`= P(搭配词|节点) − P(搭配词|非节点)，`delta_p_coll` 反向）、`z`（z-score）。

公式出处写入统计页列标题悬停与方法附录（第六节）。新增指标须加入 `tests/golden/` 的独立参考实现比对，误差 < 1e-6。

## 四 平行语料译法统计与译文条件（B2）

### 译法统计

`POST /stats/translations`：`{scope, query, unit: word|lemma, target_language?, measure: dice|ll, top: 100, min_freq: 2, exclude_punct: true}` → `Job`。

- 只用于平行语料（`corpus.parallel`），否则 422 `NOT_PARALLEL`。`scope` 通常为源语言侧（`{corpus_id, filter: language=…}`）；`target_language` 缺省为该平行语料中与命中句语言不同的一侧。
- 计算：取命中句的对齐句（`sentence_alignments`，两个方向都查），按单位统计对齐句中各词出现的句数 a；与目标侧全部对齐句中该词的句数 b、命中句数 n、目标侧句数 N 计算 Dice = 2a / (n + b) 与 LL（2×2 列联表）。
- 列：译文词、共现句数、占命中句 %、目标侧句数、Dice、LL。`totals` 增加 `hit_sentences`、`aligned_sentences`（有对齐的命中句数）、`unaligned`（无对齐句的命中句数）。
- 回到例句：行带 `search_query` = 原查询，`search_aligned: {op: "+", query: "\"译文词\""}`（词元单位用 `{lemma=…}`），打开检索时附带该译文条件。
- 统计页新增"译法"方法；检索页平行语料结果栏加"统计译法"按钮。

### 译文条件检索

`POST /search` 增加 `aligned?: {op: "+" | "-", query: string}`：只保留对齐句（任一方向）中含（`+`）或不含（`-`）`query` 命中的命中。`aligned.query` 用目标侧的查询语法（同一查询式语言，按目标侧语言的标签集编译）。

- 只在平行语料可用，否则 422 `NOT_PARALLEL`；`aligned.query` 解析错误返回 422 `QUERY_INVALID`，错误定位到译文条件输入框。
- 计数、翻页、后台计数、结果集缓存与 P7 一致；缓存键包含 `aligned`。
- 检索导出、分布统计接受同一 `aligned` 参数。
- 检索页在平行语料范围下显示"译文条件"：含 / 不含 + 查询式输入；有条件时计数卡标注"含译文条件"。

## 五 检索结果抽样编码（B6）

`POST /projects/{id}/samples`：`{scope, query, aligned?, n: 1–500, seed?, layer: {name, label_set_id}}` → `{layer_id, sampled, total}`（同步执行；需要完整命中，若计数未完成，用后台完整结果；命中超过上限或计数失败返回 409 `SEARCH_INCOMPLETE`）。

- 按 `seed`（缺省随机生成并记录）从完整命中中等概率无放回抽 n 条（n > 命中数时全取）。
- 新建 span 层（`kind=span`，单人模式，创建者为当前用户），`meta.sample = {query, scope, aligned, n, seed, total_hits, created_at}`；每条抽中的命中建一个片段：范围为命中的码点范围，`label = ""`（未编码），`status = suggested`。
- 编码 = 校对：用户在片段工作区把标签改为标签集中的某个标签（status 变 modified / confirmed）或拒绝（rejected，表示不计入）。`label = ""` 的片段不计入统计、一致性与导出。
- `GET /layers/{id}/sample-summary` → `{total_hits, sampled, coded, rejected, labels: [{label, count, pct, ci_low, ci_high, estimate}]}`：比例以已编码（不含拒绝）为分母；95% Wilson 区间；`estimate` = 比例 × total_hits（四舍五入，标注为估计）。
- 片段工作区对抽样层显示"抽样模式"：按抽样顺序逐条列出（只显示命中所在句与命中高亮），键盘流（数字键选标签、Enter 确认、X 拒绝）沿用现有片段工作区；顶部显示"已编码 n / 抽样 N"与汇总表（标签、条数、比例、95% 区间、估计命中数）。
- 检索页结果栏加"抽样编码"：选 n、标签集（可新建），确认后跳到该层。
- 权限：与现有建标注层规则一致（owner / editor；Bearer 即助手令牌可创建，助手侧走写操作确认门；annotator、viewer 403）。

## 六 方法附录与引用（B5）

`POST /projects/{id}/method-appendix`：`{stat_ids?: string[], searches?: [{query, scope, aligned?}], layer_ids?: string[], evidence?: bool, style: "gbt7714" | "apa"}` → `{markdown, citations: [string]}`；同参数 `?format=docx` 返回 DOCX 文件（同步生成，宋体标题，无底色）。

内容（只写实际用到的部分）：

1. 语料：名称、语言、文档 / 句 / 词数、来源、许可、版本、索引版本（`index_version`）；子库写筛选条件与规模。
2. 处理工具：分词与标注（jieba / Stanza 版本，中文依存模型）、CWB 版本、平台版本（`APP_VERSION`）。
3. 检索：查询式、范围、译文条件、三项计数、检索时间。
4. 统计：方法、全部参数、指标、`totals`，每个指标一句公式说明与文献（MI：Church & Hanks 1990；t：Church et al. 1991；LL：Dunning 1993、Rayson & Garside 2000；logDice：Rychlý 2008；MI3：Oakes 1998；ΔP：Gries 2013；log ratio：Hardie 2014；%DIFF：Gabrielatos & Marchi 2012；DP：Gries 2008；DPnorm：Lijffijt & Gries 2012；Juilland D：Juilland & Chang-Rodríguez 1964；Bonferroni；Wilson 区间：Wilson 1927）。
5. 标注：层名、标签集、标注人数、条目数、一致性（κ / α，若有）、抽样层写抽样方式（n、seed、总命中）与编码结果。
6. 引用：内置语料按其署名与许可、平台本身，按所选格式给出参考文献条目；文献条目信息放在 `engine/methods.py` 的静态表中，不联网查询。

- `evidence: true` 时从项目证据篮收集：统计行 → stat_id，命中 → 其来源查询与范围（若证据记录了），文本条目忽略。
- 抽样层（`meta.sample`）的查询式、范围与译文条件同时写入“检索”节，按当前正式检索计数给出命中 / 句 / 文档三项；与 `searches` 或证据中的同一检索只写一次（2026-11-07，B09）。
- 入口：证据篮"生成方法附录"、统计结果"方法说明"、标注层（抽样层）汇总"方法说明"。界面显示 Markdown 预览，可复制、下载 DOCX、"保存为笔记"（写入知识库笔记，复用现有笔记接口）。

## 九 验收

- 分解：`by=word` 各行命中数之和 = `counts.hits`；`left1`/`right1` 行点回检索的命中数等于该行命中数（抽 3 行核对）。
- 离散度：与独立参考实现（tests/golden）一致；构造均匀与集中两种分布的小语料，DP 分别接近 0 与接近 1。
- 效应量：%DIFF、odds ratio、log ratio CI、MI3、ΔP、z 与参考实现一致；`items` 返回指定词即使低于 min_freq；`direction=negative` 只含参照多于目标的词。
- 译法：Tatoeba 中英子库查 `翻译`，译法表含 translate / translation；点 translate 行打开检索，计数等于该行共现句数；`aligned` 含 / 不含两次计数之和 = 无条件计数。
- 抽样：同 seed 重复抽样得到相同命中；编码 20 条后汇总比例与区间正确；`label=""` 不进入导出与一致性。
- 方法附录：对一个统计结果和一个抽样层生成附录，含语料规模、版本、参数、公式文献与引用条目；DOCX 可打开、宋体。
- Agent：对话"统计 翻译 在 Tatoeba 的译法并比较两种译法的分布"产生 stats.translations 等工具调用并渲染表格。
- 权限矩阵补新接口；现有测试不回归。

## 十 实现说明（2026 年 11 月 6 日）

已实现，整栈联调与独立审查通过。下列各点与上文原文不同或为原文未写明的口径，以此节与代码为准。

### 分解

- 列键：`item`、`hits`、`pct`、`per_million`。命中取自与检索相同的路径，受 `SEARCH_MAX_HITS` 限制。
- 单独一个 `{…}` 或 `[…]` 的查询返回 422。
- 词元行：单槽且无同句条件时为 `{lemma=x}`；多词或带条件时用该词元在范围内各词形的选项式（`"run"|"ran"`）。
- 词形行为精确词形序列；查询带词性时，点回检索的计数可能大于该行（精确词形不带词性限制）。左一词 / 右一词行点回检索的计数与该行一致。
- 分解不接受 `aligned`。检索页有译文条件时"分解"与"统计译法"按钮禁用，悬停"含译文条件时不可用"。

### 离散度

- 只对显示的前 `top` 行计算。
- PostgreSQL 统计单位（deprel、带 `layers.pos` 的词性、span_label、relation_label）不支持离散度。
- `field:<字段>` 时缺该字段的文档同时排除出 f 与部分词数；频次列仍按全范围计。

### 效应量

- log ratio 区间：SE = √(1/a′ + 1/b′) 为自然对数尺度，区间 = log ratio ± 1.96 × SE / ln 2；频次为 0 时取 0.5，行带 `values.smoothed`，页面标"平滑"。%DIFF 与 odds ratio 同样平滑。
- Bonferroni：m = 目标与参照词型并集（单位、词元与标点排除之后），p = P(χ²₁ ≥ LL) × m，`totals.types_compared` = m。
- `direction=negative` 时 min_freq 作用于参照频次。`items` 按给定顺序返回，忽略 min_freq 与 direction。
- 排序按所选指标的绝对值，odds ratio 用 |ln OR|。
- 搭配选 `delta_p` 时输出 `delta_p_node`、`delta_p_coll` 两列，排序按 `delta_p_node`。
- 统计导出另支持 DOCX（`format: docx`）；DP、DPnorm、Juilland D、ΔP、Dice 保留 4 位小数。

### 译法

- 以源侧句为单位：n = 命中句中有目标语言对齐句的句数；a = 其中对齐译文含该词的句数；N = 范围内有目标语言对齐句的源句数；b = 其中对齐译文含该词的句数。原文"目标侧全部对齐句中该词的句数 b、目标侧句数 N"不再适用。原因：Tatoeba 一句对多句，按目标侧句计时 2×2 表不自洽，点回检索的计数也对不上。
- 只列 a/n > b/N 的词。列键：`item`、`cooc`（= a）、`pct`、`target_freq`（= b）、`dice`、`ll`。
- `totals` 另含 `hits`、`target_language`、`scope_aligned_sentences`（= N）。
- `target_language` 不是该语料已有语言时返回 422。

### 译文条件

- 对齐取两个方向；纯属性与纯片段查询（PostgreSQL 路径）也支持。
- 条件查询只在目标语言一侧检索，并有命中上限；超出时返回固定文案"译文条件命中过多，请加条件"。
- 解析错误文案"译文条件第 N 个字符：…"（422 `QUERY_INVALID`）；所需标注层缺失为 422 `INVALID_LAYER`，同样以"译文条件"开头。
- 检索页地址参数 `aligned=<JSON {op, query}>`。

### 抽样

- 权限为 WRITE：owner、editor、助手令牌（Bearer）；annotator、viewer 403。
- 零命中 422 `NO_HITS`；计数未完成且 20 秒内算不完或命中过多 409 `SEARCH_INCOMPLETE`；标签集须为片段标签集，否则 422。响应另含 `seed`。
- `sample-summary` 的 `pct`、`ci_low`、`ci_high` 为 0–1 小数；另含 `seed`，各标签带 `name`。
- 新增 `GET /layers/{id}/sample-items`：按抽样顺序返回片段、文档名与所在句，供抽样模式使用。
- 迁移 `0009_layer_meta`：`annotation_layers.meta`。
- `label = ""` 未编码：直接确认 422 `LABEL_REQUIRED`，modify 后标签仍为空同样 422；整句确认跳过；不计入标注统计、一致性、导出与 `[标签]` 检索。
- 抽样片段只能拒绝，不能删除；抽样层不能运行模型建议（422 `SAMPLE_LAYER`）。
- 抽样模式键盘：数字键选标签、Enter 确认、X / Del 拒绝、J / K 上下条。
