# P3 接口契约：标注一（词性与依存）

对应 [重构设计](../doc/platform-redesign.md) 第七节与第十二节 P3，[前端整体设计方案](../doc/frontend-design.md) 标注校对页。延续 P1、P2 约定。

## 一 范围

| 模块 | 内容 |
| --- | --- |
| 标注层 | 项目内按语料库建立 `pos` 或 `dep` 类型的标注层；标签集；预标任务；进度 |
| 校对 | 逐句读取 token 与标注；确认、修改、拒绝；整句确认；键盘流 |
| 差异 | 预标与人工结果对比视图与计数 |
| 检索与统计 | 查询式 `{pos=}`、`{dep=}`、`{lemma=}` 与 `词{dep=nsubj}` 形式；标签频次统计 |
| Agent | annot.* 工具（只读与建议，不得确认）；组件 DependencyTree、AnnotationDiff |
| 导出 | CoNLL-U（有效标注 = 人工结果优先，否则系统层） |

不在 P3：片段与关系标注、双语对齐、多人一致性（P5）；把标注写回 CWB 索引（P6 视需要）。

## 二 数据模型（迁移 0003）

| 表 | 字段 |
| --- | --- |
| label_sets | id、project_id|null（内置为 null）、name、kind: pos|dep|span|relation、language|null、labels JSONB `[{id, name, color?, description?, parent?}]`、created_at |
| annotation_layers | id、project_id、corpus_id、kind: pos|dep、name、label_set_id、source_model: string（如 `jieba 0.42`、`stanza 1.9 en`）、status: created|preannotating|ready|failed、progress JSONB `{total, suggested, confirmed, modified, rejected}`、error、created_by、created_at、updated_at |
| annotations | id、layer_id、document_id、sentence_index、token_index、label（pos 标签或 deprel）、head int|null（dep 层：句内 token 序号，0 为根）、source: system|model:<name>|human:<user_id>、status: suggested|confirmed|modified|rejected、model_label、model_head（预标原值，供差异视图）、revision int、updated_by、updated_at；唯一键 (layer_id, document_id, sentence_index, token_index) |

内置标签集：`upos`（17 个 UPOS）、`jieba`（ICTCLAS 常用 30 个）、`ud-deprel`（UD 关系 37 个 + 中文常用子类型）。项目可复制内置标签集后增删。

"有效标注"规则：`status ∈ {confirmed, modified}` 的 annotation 优先；否则用 `tokens` 表的系统值（pos / head / deprel）。`rejected` 表示该 token 不应有该层标签（dep 层不允许 rejected，只能修改）。

## 三 HTTP 接口

### 标签集与标注层

| 方法 路径 | 请求 | 响应 |
| --- | --- | --- |
| GET /label-sets?project_id=&kind= | — | 列表 `LabelSet`（内置 + 项目） |
| POST /projects/{id}/label-sets | `{name, kind, language?, labels, copy_from?}` | `LabelSet` |
| PATCH /label-sets/{id} | `{name?, labels?}` | `LabelSet` |
| DELETE /label-sets/{id} | — | 204（被层引用时 409 `LABEL_SET_IN_USE`） |
| GET /projects/{id}/layers?corpus_id= | — | 列表 `Layer` |
| POST /projects/{id}/layers | `{corpus_id, kind, name, label_set_id, document_ids?: []}` | `Layer`（自动创建预标任务 `Job` kind = preannotate，`Layer.job_id`） |
| GET /layers/{id} | — | `Layer` |
| DELETE /layers/{id} | — | 204 |
| POST /layers/{id}/preannotate | `{document_ids?: []}` | `Job`（重新预标，只覆盖 status = suggested 的 token） |

```text
Layer = {id, project_id, corpus_id, corpus_name, kind, name, label_set_id, source_model, status, job_id|null,
         progress: {total, suggested, confirmed, modified, rejected}, documents: {total, done}, error|null, created_by, created_at, updated_at}
```

预标：pos 层把 `tokens.pos` 作为 `model_label` 写入（source = `system`），全部 suggested；dep 层英文同样取系统值，中文语料先执行 Stanza 预分词依存解析（`engine.nlp.annotate_dependencies_zh`）再写入，source = `model:stanza-zh`。预标任务进度按文档计。

### 校对

| 方法 路径 | 请求 | 响应 |
| --- | --- | --- |
| GET /layers/{id}/documents | — | 列表 `{document_id, title, sentences, done, pending}` |
| GET /layers/{id}/sentences?document_id=&cursor=&page_size=20&status=pending|all | — | `{items: [SentenceAnnot], next_cursor}` |
| GET /layers/{id}/sentences/{document_id}/{sentence_index} | — | `SentenceAnnot` |
| POST /layers/{id}/annotations | `{document_id, sentence_index, token_index, action: confirm|modify|reject, label?, head?}` | `Annotation` |
| POST /layers/{id}/sentences/{document_id}/{sentence_index}/confirm | `{}` | `SentenceAnnot`（整句 suggested → confirmed） |
| POST /layers/{id}/sentences/{document_id}/{sentence_index}/reset | `{}` | `SentenceAnnot`（整句回到 suggested 与预标值） |
| GET /layers/{id}/diff?document_id=&only_changed=true | — | `{items: [SentenceAnnot], counts: {changed, confirmed, rejected, pending}}` |
| GET /layers/{id}/stats | — | `{labels: [{label, count, confirmed, modified}], progress, per_document: [...]}` |
| POST /layers/{id}/export | `{format: conllu, document_ids?}` | `Job`（kind = export） |

```text
SentenceAnnot = {document_id, sentence_index, text, tokens: [{index, form, start_cp, end_cp, system: {pos, head, deprel}}],
                 annotations: [Annotation], status: pending|done}
Annotation = {id, token_index, label, head, model_label, model_head, source, status, revision, updated_by, updated_at}
```

权限：owner / editor / annotator 可标注，viewer 只读；Bearer（Agent）只能读取与调用 `suggest`（见五）。

### 检索与统计扩展

- 查询式新增 token 属性约束 `{k=v}`，可单独或接在词后：`{dep=nsubj}`、`{pos=n}`、`{lemma=go}`、`学生{dep=nsubj}`、`"run"{pos=v}`；多个约束逗号分隔 `{pos=v,dep=root}`；值支持 `|`。`词/n` 仍为系统词性简写。
- `SearchRequest.layers?: {pos?: layer_id, dep?: layer_id}`：指定后 `{pos=}` / `{dep=}` 按该层有效标注解析；未指定按系统层。前端默认选该语料库在本项目内最近的 ready 层。
- 实现：engine 解析出属性约束；api 先在 PostgreSQL（tokens ⋈ annotations）求满足约束的 (document_id, sentence_index, token_index) 集合，再与 CWB 候选命中按 token 位置求交；纯属性查询（无词形锚点）直接由 PG 产生命中并计数。计数口径不变。
- `POST /stats/frequency` 的 `unit` 增加 `deprel`；`pos`/`deprel` 单位接受 `layers`，按有效标注计数。

## 四 engine 变更

- `engine/query`：AST 支持 `attrs: {pos?, dep?, lemma?}` 于 token 项；`compile` 对属性约束输出 `#attr` 行（token 位置、约束），由 api 解析；`parse` 对 `{…}` 不再返回"暂不支持"。
- `engine/nlp.py`：`annotate_dependencies_zh(doc)` 正式实现（Stanza zh，`tokenize_pretokenized=True`，输入 jieba token），返回每句 head / deprel。
- `engine/conllu.py`：`write_conllu(documents_with_effective_annotations) -> str`。

## 五 Agent

| 工具 | 说明 |
| --- | --- |
| annot.layers | 列出项目标注层与进度 |
| annot.create_layer | 建层并预标（可逆：删除层即撤销） |
| annot.sentence | 读取一句的 token、系统值、标注 |
| annot.diff | 读取差异计数与样例 |
| annot.stats | 标签频次与进度 |
| annot.suggest | 对指定 token 提出标签或 head 建议，写入 `status = suggested` 且 `source = model:<model_id>`，不改变已确认值；Agent 不能 confirm |
| annot.export | 导出 CoNLL-U |

组件：`DependencyTree(document_id, sentence_index, tokens: [{index, form, pos}], arcs: [{head, dep, label}], highlight?: [index])`；`AnnotationDiff(layer_id, document_id, sentence_index, tokens: [{form, model, human, status}])`。

## 六 前端

- 标注页：层列表（进度环、kind、模型、状态）、新建层对话框（语料库、类型、标签集、文档范围）；工作区三栏：文档与句子列表（待办优先）、编辑器、标签面板。
- 编辑器：pos 层 — 每个 token 下方标签 chip（suggested 虚线、confirmed 实线、modified 实线加标记、rejected 删除线），点选打开标签面板或按数字键；dep 层 — 弧线图（SVG，arcs 在 token 上方，label 在弧顶），拖动弧线端点改 head，点击弧标签改关系，根用竖线标记；两种层都支持 Enter 确认当前 token、Shift+Enter 整句确认、Del 拒绝（pos）、J/K 上下句、←/→ 切 token、`?` 快捷键表。
- 差异标签页：only_changed 过滤、计数条；统计标签页：标签频次表 + 条形图。
- 检索页：查询辅助面板加入 `{pos=}`、`{dep=}`、`{lemma=}` 插入项与层选择；KWIC 行可展开该句依存树。
- 导出 CoNLL-U 按钮（任务）。

## 七 验收

- UD 英文样本：建 pos 与 dep 层，预标值与 CoNLL-U 原值一致率 100%（系统层来自同一文件）；中文 TXT：jieba 词性预标覆盖全部 token，Stanza 中文依存预标覆盖全部句子。
- 校对 100 句（含修改与拒绝）后：`{dep=nsubj}`、`学生{dep=nsubj}`、`{pos=v,dep=root}` 返回的命中与 PostgreSQL 独立 SQL 计数一致；差异视图计数正确；CoNLL-U 导出能被 `conllu` 库解析且修改值生效。
- Agent：`annot.suggest` 只产生 suggested；对话"看第 3 句的依存树"渲染 DependencyTree。
- 浏览器：拖弧线改 head 后刷新保持；键盘流完成 20 句无需鼠标。

## 八 实现定稿说明（2026 年 10 月 27 日）

- token 序号：API 中 `tokens[].index`、`token_index`、`head` 为句内 1 起，0 为根（存储同样 1 起 = tokens.idx + 1）；`sentence_index` 仍 0 起。
- 游标：`"<document_id>:<sentence_index>"`，语料顺序（文档 created_at、id、句序）；`page_size` 1–100 默认 20；坏游标 422 `INVALID_CURSOR`。diff 同样支持游标并返回 `next_cursor`，counts 为 token 计数，`changed = modified`。
- suggest：`POST /layers/{id}/suggest {model?: "agent", document_id, sentence_index, token_index, label?, head?}` 返回 `Annotation`；token 已 confirmed / modified / rejected 时 409 `ANNOTATION_REVIEWED`；批量体 `{model?, items: [...]}` 返回 `{items, skipped}`；写入 source = `model:<model>`、revision + 1，状态保持 suggested。
- Bearer 权限：可读、suggest、建层（触发预标）、导出；confirm / modify / reject / 整句确认 / 重置 / 删层 / 改标签集仅人工（403）。契约第三节的"只读 + suggest"按第五节放宽。
- 内置标签集：jieba 含 jieba 实际输出的全部 57 个标签（单字母为父级）；ud-deprel 为 37 个 UD 关系 + 25 个子类型；`GET /label-sets` 返回 project_id 为 null 的内置集，启动时幂等写入。
- 中文依存预标：Stanza zh-hans `tokenize_pretokenized`，用 Stanza 自身 pos/lemma 作解析输入，jieba 词性不变；结果回填 tokens 中为空的 head / deprel。`source_model` 为 `jieba <ver>`、`stanza <ver> zh` 或 `system`。
- 属性查询：engine `compile` 输出 `#attr <slot> k=v|v` 与 `#target` 行；纯属性查询（单个 `{…}`，可带 `/pos`，无条件）由 PostgreSQL 直接产生命中并计数；带词锚点的查询用 CQP target 标记按 token 过滤。限制：`{…}` 不能出现在 `+`/`-` 条件与 `|` 并列中；变长间隔之后的属性只按最短匹配校验；CJK 字串带属性时按整 token 匹配；pos 值按语料标签集展开，dep 精确，lemma 不区分大小写；统计的搭配节点与分布查询不接受 `{…}`（422）。
- 统计：`unit=deprel` 或带 `layers.pos` 的词性频次在 PostgreSQL 计数，行 `search_query` 为 `{dep=X}` / `{pos=X}`，前端回到例句时须带同样的 `layers`。
- 其他错误码：422 `INVALID_LAYER`、`INVALID_LABEL`、`INVALID_HEAD`、`REJECT_NOT_ALLOWED`、`INVALID_DOCUMENTS`；409 `LABEL_SET_IN_USE`、`JOB_IN_PROGRESS`。CoNLL-U 下载为 `text/plain; charset=utf-8`。
- 已知：同批导入的文档 created_at 相同，语料顺序按 uuid；属性查询的 search_id 缓存计数在标注变化后可能过期；删除文档后层进度到下次操作才刷新。
