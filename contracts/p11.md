# P11 批次 5a：剩余缺憾与安全加固

来源：[调研报告](../doc/reviews/2026-11-05-gap-research.md) 第一节中、低优先级缺憾，第三节 P1 / P2 中的安全与可用性项。证据见 `tmp/research-2026-11-05/1-existing-gaps.md`、`3-platform-completeness.md`。不新增研究方法。

暂不做（另行决定）：合并 / 拆分词（M7，影响 CWB 位置与全部标注层）、内置与个人知识库（M15）、P2 研究能力（B16–B22）、SSO、邮件通知、存储配额、公告、指标系统、CI。

## 一 检索（实现方 A）

1. **纯属性 / 纯片段查询（M1）**：`effective.pg_search` / `span_search` 每页全量取行、无超时、每页读整篇正文。改为：与 P7 相同的"完整结果算一次、存结果集、翻页切片"，同步阶段受 `SEARCH_COUNT_TIMEOUT` 限制，超时转后台计数；SQL 设 `statement_timeout`；语境只读命中句及前后所需句子（不读整篇）；平行语料语境限在本句（与 CWB 路径一致）。
2. **检索导出（M2）**：从结果集读取，不再每 1000 条重跑；文件开头写"查询式、范围、译文条件、三项计数、导出时间、索引版本"行（与来源行同格式）；句序从 1 起，与界面一致。
3. **结果内筛选（M4）**：筛选框不再只筛当前页：输入内容作为同句条件（`+词`，可选"不含"为 `-词`）重新检索，查询式栏同步显示加上的条件；清空后恢复原查询。
4. **英文频次大小写（M3）**：频次、n-gram、关键词、搭配对英文默认按小写合并（`case_sensitive: false`，可切换），与检索的不区分大小写一致；中文不受影响。统计页加"区分大小写"开关。（engine/stats.py 归 A 本批。）
5. **简繁通查（M16）**：检索页"简繁通查"开关（中文语料默认开）：查询式中的汉字串展开为简体与繁体两种写法（`|` 并列，去重），计数与 KWIC 正常；依赖纯 Python 转换库（`zhconv` 或同等许可的 OpenCC 词典实现，写明许可）。0 命中时的简繁提示保留。
6. **KWIC 片段高亮（低）**：每行一个请求改为一页一次批量请求。

## 二 标注与知识库（实现方 B）

1. **新建层文档选择（M6）**：文档列表支持搜索与分页（不再只有前 200 篇）；可按子库选择文档范围；LLM 预标前显示"将调用模型约 N 次（按句数 / 批大小估算）"。
2. **句对齐目标句（M8）**：目标句列表改为按文档与句号检索 + 分页，不再只列前 5000 句。
3. **标注进度（M9）**：层进度计数改为增量维护（写入时更新计数），不再每次全表聚合；中文依存预标按块报进度。
4. **长文献摘要（M13）**：超过单次上限时分段摘要再合并（map-reduce，段数上限 20），任务结果写明"按 N 段摘要"；超过段数上限时只摘前 20 段并明确提示，不静默丢弃。文献术语抽取同样分段，不静默截断。
5. **笔记保存（M14）**：自动保存后 30 秒无新修改才排一次向量重建（同一笔记已有排队的不重复排）；保存带版本号，版本不符返回 409 `NOTE_CONFLICT`"笔记已被他人修改，请刷新后合并"，前端提示并保留本地内容可复制。
6. **证据去重约束（低）**：证据表加唯一约束（项目 + 命中位置，或项目 + 统计行），并发钉住同一命中只留一条（迁移 0013，存量重复合并）。
7. **平行语料的"文档"计数（低）**：平行语料的检索计数卡与统计 totals 不显示文档数（显示"句对"），避免误读。

## 三 平台与安全（实现方 C）

1. **帮助页（C16）**：新页面 `/help`（顶栏"帮助"入口与命令面板）：查询语法（可复制示例并一键在检索页打开）、导入格式与列映射、统计指标与公式（与方法附录同源的文献）、角色与权限、数据与隐私链接、常见错误。内容随代码维护在 `apps/web/src/features/help/` 的结构化数据中，不另起 CMS。
2. **解压上限（P2 安全）**：DOCX / XLSX / PDF 等压缩格式解析前检查解压后总大小（默认 500 MB，`MAX_UNPACKED_BYTES`）与文件数，超过拒绝"文件解压后过大"。
3. **URL 导入防 DNS 重绑定（P2 安全）**：解析一次域名，检查全部地址不在私网后，按该 IP 连接（保留 Host 头与 SNI）；重定向每一跳同样检查。
4. **账号探测（P2 安全）**：`GET /users?email=` 只返回精确匹配，且仅项目 owner（加成员时）可调用、按用户限流（每分钟 20 次）；不存在时与存在时响应时间与结构一致（不存在返回空列表）。
5. **上传许可字段（P2）**：上传对话框可填来源、许可、署名（写入语料或文档元数据，导出来源行使用）。
6. **模型请求重试（低）**：worker `llm.py` 与 agent 的模型调用遇到 429 / 5xx / 连接错误时有限重试（最多 2 次，指数退避 2 s、6 s，尊重 Retry-After），仍失败给出实际错误。
7. **任务列表查询（低）**：任务列表的 N+1 查询改为批量（owner、语料名等一次取回）。
8. **上传进度条（低）**：上传对话框显示真实上传进度（XHR / fetch 上传进度），大文件可取消。
9. **面包屑（低）**：顶部范围条的面包屑点击打开对应的范围切换器（项目 / 语料库 / 子库），不再打开命令面板。
10. **`corpus.parse` 工具带范围（低，agent）**：助手的查询解析工具按会话范围的语料标签集解析。

## 五 验收

- 纯属性查询在大语料（UD 中文 GSD 全量或 Tatoeba 第 1 批）上：首屏 ≤ 3 秒或转后台，翻页不重跑 SQL（测试计数），语境不读整篇。
- 检索导出：10 万条命中导出只跑一次查询；文件头含查询与计数；句序从 1 起。
- 结果内筛选与"+词"条件检索计数一致。
- 英文频次 The / the 合并；开关切换后区分。
- 简繁通查：繁体语料查简体"语言"能命中"語言"，计数等于分别查两种写法之和（去重后）。
- 新建层可选到第 201 篇以后的文档、按子库选择；对齐可选到第 5000 句以后的目标句。
- 摘要：15 万字文献按段摘要并写明段数。
- 笔记并发：两个会话同时编辑，后保存者得 409；自动保存 10 次只排 1 次重建。
- 证据：并发钉住同一命中只有一条。
- 解压炸弹 DOCX 被拒；指向私网的重绑定域名被拒（测试用自定义解析）；`/users?email=` 非 owner 403、限流生效。
- 模型 503 两次后第三次成功（假服务）。
- 帮助页各节可打开，示例查询一键检索有结果。
- 权限矩阵与现有测试不回归。

## 六 实现说明

| 节 | 实现 |
| --- | --- |
| 一.1 纯属性 / 纯片段 | `complete_rows` 对 PostgreSQL 路径与 CWB 同样产出完整命中行（文档码点），存结果集、翻页切片；SQL 在 `effective.statement_timeout` 下执行（同步 `SEARCH_COUNT_TIMEOUT`，后台 `SEARCH_FULL_TIMEOUT`），超时转后台计数。后台计数期间纯属性查询的首页按语料顺序取（`PG_PREFIX_TIMEOUT` 5 秒内，超时为空页），纯片段查询没有首页、等计数完成。语境由 `cwb.DocText` 从当前索引的 `text.bin` / `sents.bin` 读命中句与所需前后句，索引中没有的文档（索引后新增）才读正文文件。实测：Tatoeba 整库 `{pos=NOUN}` 380,100 命中完整计数 4.45–6.06 秒、中文侧 42,036 命中 0.39–0.44 秒（2026-11-07 重测更正），UD 中文 GSD 3 万命中 0.52 秒，翻页 0.03 秒 |
