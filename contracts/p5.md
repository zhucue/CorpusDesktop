# P5 接口契约：标注二（片段、关系、双语对齐、一致性）

对应 [重构设计](../doc/platform-redesign.md) 第七节与第十二节 P5。延续 P1–P4 约定，复用 P3 的标注层、标签集、校对与导出框架。

## 一 范围

| 模块 | 内容 |
| --- | --- |
| 片段标注 | 任意文本片段打标签（可跨词），属性；LLM 按标签集与规范预标 |
| 关系标注 | 片段之间有向关系；LLM 预标 |
| 双语对齐 | 句级（已有对齐、长度 + 向量相似度候选）与词级（LLM 候选）；连线图编辑 |
| 标签集模板 | 内置：学习者偏误、翻译策略 |
| 多人与一致性 | 一层多位标注者；Cohen's κ（2 人）、Krippendorff's α（多人）；仲裁 |
| 检索与统计 | `[标签]`、`词[标签]`、`[标签:属性=值]`；标签频次、关系频次、对齐统计 |
| Agent | annot.spans、annot.suggest_spans、align.candidates、align.suggest；组件 AlignmentGraph、SpanView |
| 导出 | brat standoff（.txt + .ann）、JSON、TMX（对齐）、XLSX（偏误统计） |

## 二 数据模型（迁移 0005）

| 表 | 字段 |
| --- | --- |
| annotation_layers | 新增 kind 值 span / relation / alignment；`mode: single|multi`；`annotators uuid[]`；relation 层 `base_layer_id`（片段层）；alignment 层 `src_corpus_id`、`tgt_corpus_id`、`level: sentence|word`、`guideline_document_id|null`（span / relation 层也可关联规范） |
| annotations（P3） | 新增 `annotator_id`（默认创建者），唯一键改为 (layer_id, document_id, sentence_index, token_index, annotator_id) |
| span_annotations | id、layer_id、annotator_id、document_id、sentence_index|null、start_cp、end_cp、label、attrs JSONB、source、status、model_label、model_attrs、revision、updated_by、updated_at |
| relation_annotations | id、layer_id、annotator_id、from_span_id、to_span_id、label、source、status、model_label、revision、updated_by、updated_at |
| alignment_annotations | id、layer_id、annotator_id、src_document_id、src_sentence_index、tgt_document_id、tgt_sentence_index、src_tokens int[]（1 起，句级为空）、tgt_tokens int[]、score、source、status、revision、updated_by、updated_at |
| adjudications | layer_id、target_kind: token|span|relation|alignment、target_key（文本键）、final JSONB、decided_by、decided_at |

内置标签集（kind = span）：`learner-errors`（时态、体、冠词、介词、搭配、词序、主谓一致、拼写、漏词、多词、用词、句式、标点）和 `translation-strategies`（直译、意译、增译、减译、词类转换、语态转换、分句、合句、归化、异化、音译、省略）；kind = relation：`error-correction`（correction、cause）。

## 三 HTTP 接口

### 层与预标

- `POST /projects/{id}/layers` 扩展：`kind: span|relation|alignment`，`mode`，`annotators`，`base_layer_id`，`src_corpus_id/tgt_corpus_id/level`，`guideline_document_id`，`document_ids`。span / relation 层预标任务：把每句（或段落）连同标签集说明与规范摘录（≤ 2000 字）发给对话模型，解析 JSON `[{start_cp, end_cp, label, attrs}]` / `[{from, to, label}]`，status suggested，source `model:<MODEL_ID>`；失败句记录在 `progress.failed_sentences`。alignment 层预标：句级优先用 sentence_alignments，否则按长度比 + MiniLM 余弦（阈值 0.5）生成候选；词级把句对交给对话模型，得到 `[{src: [i…], tgt: [j…]}]`。
- `POST /layers/{id}/preannotate` 同 P3，可带 `sentence_range`。

### 校对

| 方法 路径 | 请求 | 响应 |
| --- | --- | --- |
| GET /layers/{id}/spans?document_id=&cursor=&status= | — | `{items: [SentenceSpans], next_cursor}` |
| POST /layers/{id}/spans | `{document_id, start_cp, end_cp, label, attrs?}` | `Span`（status confirmed，source human） |
| PATCH /layers/{id}/spans/{span_id} | `{action: confirm|modify|reject, label?, start_cp?, end_cp?, attrs?}` | `Span` |
| DELETE /layers/{id}/spans/{span_id} | — | 204（仅人工创建的） |
| POST /layers/{id}/relations | `{from_span_id, to_span_id, label}` | `Relation` |
| PATCH /layers/{id}/relations/{rel_id} | `{action, label?}` | `Relation` |
| GET /layers/{id}/alignments?src_document_id=&cursor= | — | `{items: [SentencePair], next_cursor}` |
| POST /layers/{id}/alignments | `{src_document_id, src_sentence_index, tgt_document_id, tgt_sentence_index, src_tokens?, tgt_tokens?}` | `Alignment` |
| PATCH /layers/{id}/alignments/{aid} | `{action: confirm|modify|reject, src_tokens?, tgt_tokens?, tgt_sentence_index?}` | `Alignment` |
| GET /layers/{id}/agreement | — | `{annotators: [{user_id, email, done}], pairwise: [{a, b, kappa, n}], alpha, per_label: [{label, kappa}]}` |
| GET /layers/{id}/disagreements?cursor= | — | 标注者结果不一致的目标列表 |
| POST /layers/{id}/adjudicate | `{target_kind, target_key, final}` | `Adjudication` |
| POST /layers/{id}/export | `{format: brat|json|tmx|conllu|xlsx}` | `Job` |

```text
SentenceSpans = {document_id, sentence_index, text, start_cp, end_cp, spans: [Span], relations: [Relation]}
Span = {id, start_cp, end_cp, text, label, attrs, source, status, model_label, revision, annotator_id, updated_at}
Relation = {id, from_span_id, to_span_id, label, source, status, revision, annotator_id}
SentencePair = {src: {document_id, sentence_index, text, tokens}, tgt: {...}, alignments: [Alignment]}
Alignment = {id, level, src_tokens, tgt_tokens, score, source, status, revision, annotator_id}
```

一致性计算：token 层按 token 标签，span 层按（start_cp, end_cp, label）精确匹配并给出重叠宽松版本，alignment 层按词对集合；只统计所有参与者都已完成的目标；κ 用 Cohen，α 用 nominal Krippendorff。`mode = multi` 时每位标注者只看到自己的标注；owner / editor 可看全部并仲裁；仲裁结果作为有效标注。

### 检索与统计扩展

- `[标签]`、`[标签:k=v]`、`词[标签]`：api 在 span_annotations（有效标注）求 (document_id, start_cp, end_cp) 集合；纯片段查询直接从 PG 产生命中（命中跨度 = 片段）；带词锚点时要求词跨度落在片段内。`SearchRequest.layers.span?: layer_id`。
- `POST /stats/frequency` `unit` 增加 `span_label`、`relation_label`；`POST /stats/distribution` 的 `query` 允许 `[标签]`；新增 `POST /stats/alignment {layer_id}` → 句对数、一对一 / 一对多 / 未对齐计数、平均词对数。

## 四 Agent

| 工具 | 说明 |
| --- | --- |
| annot.spans | 读一句的片段与关系 |
| annot.suggest_spans | 对指定句提出片段/关系建议（suggested） |
| align.pairs | 读句对与对齐 |
| align.suggest | 提出词级对齐建议 |
| annot.agreement | 读一致性 |

组件：`SpanView(document_id, sentence_index, text, spans: [{start, end, label}], relations: [{from, to, label}])`（start/end 相对 text）；`AlignmentGraph(src_tokens: [string], tgt_tokens: [string], links: [{src: [i], tgt: [j], status?}])`。

## 五 前端

- 标注页新增三种层的工作区：片段 — 文本流中拖选创建片段、标签面板、片段 chip 带属性弹层、关系用点击两片段 + 标签连线；双语对齐 — 左右两栏，词级连线，点击源词与目标词切换连线，句级下拉改目标句，候选分数显示；一致性标签页 — 标注者进度、κ / α、分歧列表、仲裁（选择某人结果或手改）。
- 新建层对话框按 kind 显示对应字段；标签集模板可一键复制。
- 检索页 `[标签]` 插入项与片段层选择；KWIC 行片段高亮。
- 统计页 span_label / relation_label 单位与对齐统计。
- OpenUI：SpanView、AlignmentGraph 卡片。

## 六 验收

- 上传一篇学习者作文 TXT，用 learner-errors 标签集与规范预标，校对后导出 brat（.ann 行数 = 有效片段数 + 关系数）与 XLSX 偏误分布；`[偏误:时态]` 命中与 SQL 一致。
- sample.tmx 与 Tatoeba 子库各建对齐层：句级候选覆盖全部句对；词级建议后修改 200 句对（脚本）并刷新保持；TMX 导出可被 TMX 解析器读取且含修改。
- 两位标注者在同一层标注 50 句后一致性页显示 κ、分歧列表；仲裁后有效标注变化反映在检索中。
- Agent："标出这句里的翻译策略"产生 suggested 片段并渲染 SpanView；"看这对句子的对齐"渲染 AlignmentGraph。
