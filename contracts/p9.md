# P9 批次 3：多人运营

来源：[调研报告](../doc/reviews/2026-11-05-gap-research.md) 第四节批次 3（C6、C7、C9、C10、C11、C15、M5、M11、H2），另加 C14（nginx 安全响应头）。面向多个课题组共用一台服务器：看得见模型用量并能限额，管理员有跨项目视图，敏感操作留痕，误删项目可恢复，过期文件自动清理，用户能反馈问题。

## 二 大模型用量与限额（C6）

- 记录：每次调用对话模型后写一行 `llm_usage`，token 数取模型响应的 `usage`（无 usage 时按字符数 / 2 估算并在 `source` 后加 `:estimated`，例如 `agent:estimated`）。agent 服务每轮模型调用写一行（`source=agent`，带 `session_id`）；worker 的 `llm.py` 每次调用写一行（`source` 为任务类型，带 `job_id`、`user_id`=任务发起人、`project_id`）。直接 SQL 插入。
- 限额：环境变量 `LLM_MONTHLY_TOKENS_PER_USER`（默认 0 = 不限）。当月（服务器本地时区自然月）该用户 `total_tokens` 之和 ≥ 上限时：agent 新消息、LLM 片段预标、文献摘要、文献术语抽取、模型对齐候选在**发起时**返回 429 `LLM_QUOTA_EXCEEDED`"本月模型用量已达上限（{上限} token），请联系管理员"；已在运行的不中断。
- 并发：同一用户同时运行的助手会话最多 2 个（`AGENT_MAX_RUNS_PER_USER`，默认 2），超出返回 429 `TOO_MANY_RUNS`"已有 2 个对话在运行，请等待完成或停止后再试"。
- 接口：`GET /me/llm-usage` → `{month, total_tokens, limit|null, by_source: [{source, total_tokens}]}`；`GET /admin/llm-usage?month=YYYY-MM&group=user|project` → `{items: [{key, name, total_tokens, prompt_tokens, completion_tokens, calls}], total}`。
- 前端：设置 · 账号显示"本月模型用量 N token / 上限 M"；管理员"用量"标签按用户 / 项目、月份切换。

## 四 审计日志（C9）

- 记录以下操作（成功时写；登录失败也写）：`login`、`login_failed`（detail 记邮箱，`actor_id` 为空）、`password_change`、`password_reset`、`user_create`、`user_disable`、`user_enable`、`admin_grant`、`admin_revoke`、`member_add`、`member_remove`、`member_role`、`project_delete`、`project_restore`、`project_purge`、`project_owner`、`corpus_delete`、`document_delete`、`subcorpus_delete`、`layer_delete`、`kb_document_delete`、`job_cancel_admin`。`target_name` 记删除前的名称。`ip` 取 `X-Forwarded-For` 最后一个地址或客户端地址。
- 写入与业务操作在同一事务；集中在 `services/api/audit.py` 的 `record(db, user, action, target_type, target_id, target_name, project_id=None, detail=None, request=None)`。
- `GET /admin/audit?actor=&action=&project_id=&from=&to=` 分页；`GET /projects/{id}/audit` 项目负责人可看本项目条目。
- 不清理（数据量小）。

## 五 项目软删除与清理（C10、C11）

- `DELETE /projects/{id}`：设 `deleted_at`，不删数据与文件；写审计 `project_delete`。之后项目对所有接口如同不存在（404，含 Bearer 与 agent 令牌），不出现在项目列表；成员看到"你已不是该项目成员"页（沿用现有）。删除确认框写明"7 天内可由负责人或管理员恢复"。
- `GET /me/deleted-projects`（本人为 owner 且 7 天内删除）；`POST /projects/{id}/restore`（owner 或管理员，浏览器会话；超过 7 天返回 410 `PURGED`）。设置 · 项目显示"最近删除"列表与恢复按钮。
- 清理（worker 维护任务，见下）：`deleted_at` 超过 7 天的项目执行现有的硬删除（数据库级联与文件），写审计 `project_purge`（`actor_id` 为空）。
- 维护任务：worker-light 每小时检查一次，距上次运行超过 24 小时就执行（上次时间记在 `DATA_DIR/maintenance/last-run`）：清除过期软删除项目；删除 30 天前完成的导出文件（之后下载返回 410 `EXPORT_EXPIRED`"导出文件已过期，请重新导出"）；删除 30 天前失败或取消的导入上传目录。保留期用 `PROJECT_PURGE_DAYS`（7）、`EXPORT_RETENTION_DAYS`（30）配置。运行结果写 worker 日志一行。

## 六 站内反馈（C15）

- 外壳顶栏"反馈"按钮（图标 + tooltip"反馈问题"）→ 对话框：文本（1–2000 字），自动附当前页面路由与 `APP_VERSION`；不附项目内容。提交后提示"已收到"。
- `POST /feedback` `{text, page, project_id?}`（登录即可，浏览器会话；Bearer 403）；`GET /admin/feedback?status=`；`PATCH /admin/feedback/{id}` `{status, admin_note}`。
- 管理"反馈"标签：列表（时间、用户、页面、内容、状态）、标记已处理与备注。

## 七 取消可中断（M5）

- 统计任务：传入取消检查函数给 engine 的计算（CQP 子进程用 P7 已有的 `cancel` 参数；Python 循环每处理约 1 秒检查一次），检查函数复用 `Run.progress` 的状态读取（每 2 秒最多查一次库）。取消后 3 秒内释放 worker。
- 预标注（Stanza 分块、LLM 批次）、知识库摘要与抽取、导出：每块 / 每批之间检查。
- 验收：大统计任务运行中取消，worker 在 5 秒内开始处理下一个任务（测试可用小超时与慢速假引擎）。

## 八 索引过期与自动重建（M11）

- 删除文档、修改文档元数据（标题除外）、批量改元数据后，自动为该语料排一个建索引任务；若已有排队中的该语料建索引任务则不重复排。
- `Corpus` 视图增加 `index_pending: bool`（有排队或运行中的建索引任务）。检索页、统计页在当前范围的语料 `index_pending` 时显示一行"索引更新中，完成前结果可能包含已删除或修改前的文档"。索引完成后按现有 `index_version` 机制使旧 search_id 失效。

## 九 非中英文语料（H2）

- 上传时指定语言不是 zh / en（CoNLL-U 除外：自带分词与标注，不跑 NLP）：422 `LANGUAGE_UNSUPPORTED`"暂只支持中文与英文语料"。
- TMX 中含 zh / en 以外的语言：导入失败，错误"TMX 含暂不支持的语言：fr"（列出语言码）。
- 自动识别：文本主体（去空白与标点后）为非汉字非拉丁字母（西里尔、假名、韩文、阿拉伯文等）占比 > 30% 时导入失败"未识别为中文或英文，请确认语言；暂只支持中英"；拉丁字母文本中英语高频功能词（the, of, and, to, a, in, is…前 50 个）占词数 < 3%（且词数 ≥ 200）时同样失败并提示"可能不是英文"。
- 错误在任务详情与上传结果中显示。

## 十 nginx 安全响应头（C14）

`deploy/nginx.conf` 对页面与接口加：`X-Content-Type-Options: nosniff`、`X-Frame-Options: SAMEORIGIN`、`Referrer-Policy: same-origin`、`Permissions-Policy: camera=(), microphone=(), geolocation=()`。不加 CSP（OpenUI 与 ECharts 内联样式较多，另议）。

## 十二 验收

- 用量：一次助手对话与一次 LLM 预标后 `llm_usage` 各有记录、token 与模型响应一致；设上限后第二次发起返回 429；第 3 个并发助手会话 429。
- 管理：非管理员与 Bearer 访问 /admin/* 403；改派负责人后原 owner 为 editor；全局任务可取消。
- 审计：表中列出的操作各产生一条；登录失败有记录；项目负责人只能看到本项目条目。
- 软删除：删除后项目接口 404（含 Bearer）、7 天内恢复后数据完整（检索、标注、知识库可用）；维护任务清除超期项目并删文件。
- 清理：30 天前的导出被删，下载 410。
- 反馈：提交、管理员列表、标记处理。
- 取消：长统计取消后 5 秒内 worker 空闲。
- 索引：删除文档后自动建索引，完成前检索页显示提示，完成后已删文档不再出现。
- 语言：上传法语 TXT（指定 / 自动）、含 fr 的 TMX 均给出明确错误。
- 响应头：`curl -I` 可见四个头。
- 权限矩阵补全部新接口；现有测试不回归。
