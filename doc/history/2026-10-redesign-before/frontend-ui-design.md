# 前端 UI 设计方案

本方案对应 `tmp/ui-v5/`（v2.1）。第二版最初采用青蓝紫渐变，用户在评审中明确否定“炫彩”效果，因此保留 v2 的对话式助手与信息结构，把视觉收敛为仪器感科技风：近黑石墨底、1 px 细线、单一冷蓝强调色、等宽字体细节，不使用彩虹渐变、彩色光晕和大面积玻璃模糊。`tmp/ui-v4/`（渐变版）、`tmp/ui-v3/`（学术黑白版）、`tmp/ui-tech/`、`tmp/ui-redesign/` 作为历史设计保留。

研究助手仍是默认入口与统一调用入口，基于 Pi SDK 改造并作为系统内置能力呈现，不出现 Pi 产品或原生窗口。正式接口沿用《前端与接口设计规范》，权限与业务能力沿用《研究助手业务能力与工具契约》。原型使用示例数据和确定性模拟，不代表真实模型或后端已经接入。

## 一 设计方向

研究生日常在检索、比对、统计和记录之间切换，需要一屏看到结果与证据，也需要清楚任务正在做什么。v2.1 按“研究仪器”而不是“消费级应用”来做：界面本身退到背景，数据、原文和运行状态占据前景；颜色只用来标记交互与状态，不承担装饰。

| 上一版做法 | 本版处理 |
| --- | --- |
| 青蓝紫渐变、彩色光晕、玻璃卡片 | 近黑石墨底、1 px 冷白细线、实色面板；只在交互与状态上使用一种冷蓝 |
| 渐变数字、渐变按钮、渐变进度条 | 数字与按钮改为单色；进度条改为 2 px 单色细线，运行中做短段位移 |
| 彩色胶囊状态 | 方块加等宽文字，如 `■ READY`、`■ 运行中`，不使用底色胶囊 |
| 大标题渐变强调 | 标题白色，最多一个短语使用冷蓝 |
| 装饰背景：极光、扫描、光斑 | 仅保留低对比格栅与轻微暗角；不使用动态光斑 |
| 圆角卡片与投影 | 6 至 10 px 圆角、无投影；层次由描边、留白和字重建立 |

科技感来自精度而不是颜色：等宽编号与计数、统一的 8 px 网格、可对齐的表格、细线分区、短暂而明确的动效。任何颜色都对应一种状态，任何动画都对应一次真实操作。

表格是主要信息载体：表头 9.5 px 等宽、字距 0.14 em，行高约 34 px，数值右对齐等宽，行悬停为 3.5% 白层，选中行左侧 2 px 强调条。状态不使用彩色胶囊，而是 5 px 方块加等宽文字；运行中的方块缓慢呼吸。

## 四 研究助手

助手页采用对话式工作台，把任务、过程、结果和证据放在同一条时间线上。

| 区域 | 内容 |
| --- | --- |
| 空态 | 等宽标签、主标题、范围说明与四张任务卡片；输入框留在底部 |
| 用户消息 | 右对齐实色消息块，显示内容与等宽时间 |
| 助手消息 | 方形描边头像、等宽名称、模型标识、时间与状态；下方为回答、过程和结果 |
| 执行过程 | 折叠面板，逐行显示工具名、动作与真实计数；状态用 ○ / ● / ▸ 表示等待、完成、运行 |
| 回答 | 逐字输出，关键数字为等宽并带下划线；完成后保留完整段落 |
| 结果卡片 | 查询、统计、双语、笔记四类；查询卡片含三项计数、三条 KWIC 与坐标 |
| 引用 | 等宽短标签 `[S0101 0:2]`，点击打开右侧证据检查器 |
| 操作 | 打开完整结果、保存为笔记、停止、在分析页继续等 |
| 输入区 | 细边输入框、自动路由、当前快照、发送；忙时显示排队提示 |
| 上下文栏 | 快照卡片、本次结果、证据引用、可用工具 |

运行时反馈保持克制：顶部 1 px 冷蓝线做短段位移表示会话正在执行；状态文字显示“运行中”；当前步骤出现横向扫光；回答带 1 px 光标逐字输出；计数从 0 滚动到真实值；卡片与 KWIC 行以 3 px 位移淡入。停止后保留已完成步骤并显示“已取消”，输入与快照不变。

### 任务解析

原型按关键词路由到检索、统计、解释、双语与笔记五类动作，并为每类生成固定工具步骤。显式“检索「词」”优先按检索执行；带“解释”但没有明确检索对象的请求按解释处理，引用上一条查询运行；无法匹配时明确说明可执行动作，不编造结论。正式实现以服务端能力目录、权限和工具结果为准。

### 范围与会话

会话固定当前快照；切换快照后新建会话，不继承旧消息与结果。发送期间再次发送进入排队，当前运行结束后按顺序执行。新建会话清空消息、结果与引用，不保留旧上下文。快照未就绪时输入与发送禁用，并说明原因。

## 五 检索与其他页面

检索页顶部保留紧凑查询条；三项计数放在一条带分隔线的面板里，数字等宽显示，先显示未知，完成后从 0 滚动到真实值。KWIC 左侧右对齐、命中冷蓝下划线、右侧左对齐，来源与码点区间等宽显示；行悬停淡入，点击打开证据。结果内筛选不重新执行；排序、保存查询、导出 CSV 只作用于当前结果。

双语页以四格统计条给出源句、译句、关系与修订，对齐行放在独立面板中，一对多关系纵向排列并标记只读；一对一待复查关系提供接受与拒绝。分析页的方法、参数与分母保留在工具条与摘要行，结果表数值右对齐，旁边以前八项单色条形图对照；参数修改提示重新运行。

笔记页为左列表右编辑器，草稿与已接受使用方块状态，接受修订需要确认弹层，未保存切换先确认。任务页的进度使用 2 px 单色细条与百分比，总量未知时只显示已处理量；取消先进入“已请求取消”，重试创建新的执行尝试。来源、材料与同步页使用细线表格与右侧检查器，状态、许可和能力按真实字段展示。

## 六 状态与键盘

| 操作或状态 | 行为 |
| --- | --- |
| 提交查询 | 先显示未知总数，完成后滚动计数并逐行淡入 |
| 助手执行 | 顶部细线位移、状态呼吸、步骤扫光、流式回答与结果卡片 |
| 停止运行 | 保留已完成步骤，标记已取消，输入与快照不变 |
| 切换快照 | 新建会话，清空旧消息与结果，保留查询草稿 |
| 空数据 | 给出可执行的下一步，不使用静态占位 |
| 失败与受限 | 显示实际错误码与原因，保留可修改的输入 |
| 未保存修改 | 切换笔记或离开前确认一次 |

快捷键：Ctrl K 打开命令面板，方向键选择、Enter 执行；Escape 依次关闭面板、弹层与检查器；“/”聚焦主查询。所有图标按钮提供可访问名称，主要操作可键盘到达。系统开启减少动态效果时，位移、扫光、流式与计数动画降为即时呈现。

## 七 实现边界与入口

当前入口为 `tmp/ui-v5/index.html#assistant`，本机预览为 `http://127.0.0.1:8852/#assistant`，启动命令为 `node tmp/ui-v5/serve.cjs 8852`。原型为静态 HTML、CSS 与原生 JavaScript，无需构建，可直接用浏览器打开。

查询、统计、证据、笔记、任务、同步、对齐和助手均为内存示例，刷新后重置；文件上传只经过浏览器选择，不传输内容。助手按固定规则生成回答与步骤，未连接模型。正式开发按现有路由与接口替换示例逻辑，保留未知计数、固定运行参数、证据坐标、快照上限、排队与停止、接受与拒绝的确认边界。

当前交付用于视觉与交互评审，不代表真实同步、持久化、身份权限、模型接入或阶段验收已经完成。
