## 来源与研究样本

来源登记在 `pipelines/sources/registry.json`，实际网络请求、已获取字节的 SHA256、结果和待办汇总在 `pipelines/sources/s0-evidence.json`。下载文件、许可原件和完整运行 manifest 在 `tmp/sources-s0/`；临时目录被忽略，不作为可长期依赖的发布存储。正式来源发布前须将原件和 manifest 移入受控对象存储，并保存可重现引用。

### Tatoeba 中英直接句对

官方周导出采用 `cmn_sentences_detailed.tsv.bz2`、`eng_sentences_detailed.tsv.bz2` 和 `cmn-eng_links.tsv.bz2`。下载页说明详细句子保留句 ID、语言、文本、用户名、创建及修改时间，Links 表示直接翻译关系。中文包约 1.72 MB，直接关系包约 0.48 MB，英语包约 34.94 MB；获取三者不等于获取所有语言的完整 Tatoeba。

抽样固定种子 `corpus-s0-20261016-v1`。对中英正文均存在的唯一直接边计算 SHA256(seed:cmn_id:eng_id)，按摘要及端点排序选取前 10000 对，保存双侧句 ID、边 ID、作者和来源 URL。不得以间接翻译关系补足数量，不把双语展开行重复计入单语词频。样本用于开发流程验证，不代表平衡通用语料。

三文件已完整下载，Last-Modified 均为 2026 年 10 月 10 日；主 agent 独立复核完整 SHA256 与 manifest 一致。中文文件含 89179 句，英语文件含 2038719 句，交集内唯一直接关系 78089 条，已确定性选取 10000 对并保存 ID 清单与正文样本。运行目录为 `tmp/sources-s0/20261016-tatoeba-curl/`。上游 URL 会更新，因此重现旧样本依赖保留取得的原件，不能只保存 URL。

官方下载页声明 CC BY 2.0 FR，并另有 CC0 子集；本次不假定普通导出属于 CC0。署名保留句子页面链接和当前 owner，正式导出仍须核对署名要求及贡献者记录。模型外发未获核准。

英文 19 个 current 分片已通过 HEAD 核实体积，最小为 2,154,933,323 字节（p43486390p48278244），见 `pipelines/sources/enwiki-shard-sizes.json`。此前首次 GET 在 1,059,421,831 字节处因连接中断失败，一次核验 ETag、Last-Modified 和总长后的 206 续传又在取得 73,055,838 字节时中断。两份原件和永久失败证据 `pipelines/sources/enwiki-transfer-evidence.json` 保留。

针对这两次实际长连接故障，本轮重新核对同一固定 URL、强 ETag、Last-Modified、总长和官方 SHA256SUMS，将两份连续旧字节仅作为未验证前缀，余下范围按 64 MiB 分段请求。每段核对 206、Content-Range、长度和版本，版本或位置不符立即失败；网络或短 body 每段仅允许一次重试。实际 16 段全部首次完成，新取得 1,022,455,654 字节。流式拼接后完整 2,154,933,323 字节的官方 SHA256 `c15900c039cbc2dbea04f87e5eccf76dc009e0d9c2c71cc9267e039fc26b8f9c` 通过，主 agent 独立复核一致；不把组装文件伪装成一次完整 HTTP 200 请求。

随后遍历整个英文分片，在 349408 篇命名空间 0、非重定向且非空文章中，以固定种子按 SHA256(seed:page_id:revision_id) 选取 1000 篇，保留原始 wikitext、ID、出处与许可字段。样本只代表该固定分片，不是全库随机样本。主 agent 核对样本摘要、1000 个唯一 page/revision ID、排序及清单一致，两个前缀与 16 段连续覆盖整包，运行源码快照与当前代码一致。永久恢复证据为 `pipelines/sources/2026-10-16-enwiki-ranges.json`，manifest 与样本在 `tmp/sources-s0/20261016-enwiki-ranges/`；来源汇总与注册表已同步。下载、整包校验与全片抽样均有独立成功事实，无活跃下载或解析进程。

中文清洗采用隔离环境中的 `mwparserfromhell 0.7.2`，固定官方 Windows CPython 3.12 wheel SHA256，主工程依赖未改变。真实 1000 篇在 Python 3.12.13 下耗时 11.375 秒；972 篇输出受限文字子集，共 845303 码点，28 篇因残留未解析 markup 被拒绝并保留错误。永久结果、每篇原文与正文摘要、recipe 和失败清单为 `pipelines/sources/2026-10-16-zhwiki-cleaning.json`；含映射的正文输出在 `tmp/source-cleaning-s0/results/cleaned.jsonl`。

清洗保留普通文本、主命名空间链接的显示文案及受支持的无属性格式标签；模板、表格、注释、引用、命名空间链接和不支持的标签整体排除，记录原文区间，并插入无原文坐标的合成分隔。检索必须按独立 index_segments 建索引，禁止跨排除边界拼成短语或 gap 命中。原文和正文均采用 Unicode 码点左闭右开坐标；精确复制区间可逐码点回查，实体解码返回整个实体来源区间，合成分隔明确无来源，不伪造字符位置。保留原 page/revision 与出处，不做模板展开、繁简转换或 NFC；这是可追溯的受限子集实验，不是完整 MediaWiki 渲染或正式正文覆盖验收。六项代表性测试覆盖删除边界、链接文案、emoji、组合字符、多码点实体及拒绝路径。主 agent 独立核对全部 972 份输出的 98067 个映射跨度、原文与正文摘要、解码和合成分段一致，输出与 28 份拒绝记录恰好覆盖 1000 份输入。

英文 1000 篇复用同一固定解析器和清洗 recipe，在独立输出目录运行 13.547 秒，保留 996 篇受限正文、2,223,993 码点，4 篇因未解析 markup 明确拒绝。主 agent 独立核对 131358 个映射跨度、源与正文摘要、实体与空白转换、合成边界及 index_segments 一致，输出和拒绝清单完整覆盖输入；隔离解析器环境本轮复跑六项清洗测试全部通过。永久报告为 `pipelines/sources/2026-10-16-enwiki-cleaning.json`，正文和映射为 `tmp/source-cleaning-s0/enwiki-results/cleaned.jsonl`，中文既有输出未覆盖。

早期 legacy 导出路径的探测单独保留为历史证据，汇总程序拒绝以 legacy 结果满足 current 基线。来源许可按 Wikimedia 使用条款及页面适用条款登记，署名保留标题、固定修订链接、历史链接及改动记录；来源发布和模型外发未获核准。

## 业务契约与检索

`contracts/` 登记 source、snapshot、evidence、session、run、invocation、job 的基本关系，包含三种会话作用域、固定范围、异步结果、事件和常见错误。能力清单对应文档动作，生产 Pi 可调用工具仍为空；S1 当前用户能力接口另按会话与项目权限返回已实现的手动动作，不把实现进度当成授权。

S0 原有 13 项契约测试通过；S1 扩展后为 20 项及 8 个子用例通过。认证、项目、上传和任务子集已接入 Pydantic/OpenAPI、手工维护的共享 TypeScript 类型客户端、数据库约束、实时权限及任务取消；Pi 身份与运行账本基础已经验证；其余动作、正式归档和恢复仍待实现与验收。continuation 目前只建模 corpus.search；不能将通用 JSON 字段解释为后端支持任意操作。人工确认仍须接入真实用户核对依据。

查询原型采用 `corpus-query/v1` 的受限子集，返回 Unicode 码点左闭右开区间。23 条金标包含重叠匹配、重复材料、句界、跨词字串和锚点布尔计数；整数计数以独立预期验证。`A AND B` 返回 A 命中而不生成笛卡尔积，OR 按跨度去重，纯 NOT 被拒绝；regex 明确不支持，不返回空结果冒充成功。

Linux 官方 CWB 3.5.0 已真实执行；本轮主 agent 独立在禁网容器运行完整 query 套件，37 项测试通过且无跳过，包含金标、首屏与精确计数、真实 UD 导入、身份兼容、报告写入故障及优化回归。其中 CQP 对照 7 个正向 token 金标，包括变长 gap 的多个终点和 OR 嵌套跨度。报告 `tmp/query-s0/verification.json` 保存软件包 SHA256、依赖版本和实际输出。当前仅验证受限 CWB 适配，不能代表完整 CQL 或 S5 的 200 条验收。

正式规模实验仍须完成。门槛保持：先 100 万 token，再 1000 万 token，中文字符至少 1000 万码点；预热后 20 条不同选择率查询、5 并发、每条 20 次；首屏 P95 不超过 3 秒，普通查询全计数不超过 30 秒，高频字距全计数不超过 120 秒。不得用小样本金标通过替代性能结论。

已完成 Python PositionIndex 原型的三个规模探索实验；这不是 CWB 性能数据。每组均执行 20 条混合查询、每条 20 次、5 个并发线程，400 次完整查询。永久汇总为 `pipelines/query/results/2026-10-16.json`。

### 首屏与完整计数分离验证

本轮已实现并实测有限首屏与独立完整计数。CQP 内部对固定 gap／OR 分支的完整命名结果取并集，首屏仅 dump 所需的 50 条并映射 KWIC；这是限制输出，不是提前停止 CQP 求值。独立计数进程通过完整结果 size 和结构扩展去重返回命中、句和文档数。首屏的三项总数均为 null、count_status 为 pending，计数 future 完成后才发布精确数；某些计数实际早于首屏完成，报告分别记录，不把异步调度等同于必定晚完成。

实验沿用已校验摘要的百万与千万 token 原始输入和索引，各执行 20 条普通查询、每条 20 次、5 个会话。每请求同时启动独立首屏和计数调用，最多 5 个首屏与 5 个计数进程竞争同一 4 CPU／8 GiB 容器；两规模各 400 次测量均记录到实际执行重叠。会话等待自身计数结束后才接下个请求，计数用时从原请求开始计算，包含排队。永久汇总为 `pipelines/query/results/2026-10-16-cwb-paged-capacity.json`。
