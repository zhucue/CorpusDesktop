# 高校研究生语料与 AI 研究工作台 完整设计规划

建设面向高校研究生的网页语料与 AI 研究平台。研究助手工作台是默认入口，可按用户授权调用全部已上线业务能力，贯通资料同步、选材、检索、对齐、分析及成果。手动工具保留独立入口，共用相同结果和版本。首版交付真实同步与分析闭环，对标 CCL、BCC 等语料库的研究流程。

### 一 产品目标与完整形态

主要用户为高校硕士和博士研究生，优先支持外语、翻译、语言学及应用语言学，同时为文学、传播学和数字人文提供文本与话语研究能力。导师、课题组成员和数据管理员作为协作角色。研究生既可以个人使用，也可以在课题组或学校环境内协作。

| 建设目标 | 完整规划 |
| --- | --- |
| 专业工具覆盖 | 覆盖主流语料工具中的建库、检索、词频、关键词、搭配、分布、标注、双语、多模态、可视化与导出。 |
| AI 研究辅助 | 以研究助手工作台调用全部已上线业务能力；后续功能与工具同批交付，按当前角色和来源权限执行。 |
| 成果可信 | 数字来自计算工具；证据回到原文；人工修改有记录；研究范围、算法、模型与参数均可追溯。 |
| 资源可扩展 | 同时管理个人材料、课题组语料、开放资源和已授权的机构资源，并显示每个来源实际允许的能力。 |
| 交付方式 | 网页端优先，部署于平台或高校服务器。第一阶段即提供账号、项目隔离、来源同步、后台任务、备份和 AI 数据策略。 |

### 规划范围

本版为 2026 年 10 月 16 日修订基线，包含完整产品形态、96 项功能目录、第一阶段 M01 至 M14 功能边界、来源全景、对标验收及开发顺序。M 项定义首版可交付子集，F 项保留长期覆盖范围。收费与商业定价不纳入本次规划。

“完整覆盖”以明确的功能目录和场景测试为准，持续增补。资源能被发现、能够检索、可以下载分析和允许导出分别记录；资源目录中的一个链接不等于已经取得全文接入能力。

## 本版产品基线与数据覆盖

第一阶段以研究助手工作台贯通数据同步和分析。管理员可通过助手或管理页面发布平台语料版本，学生选择并固定研究材料，执行检索、对齐、比较和成果保存。公共来源与个人上传各自保留来源、许可及版本；全部已上线业务动作按用户权限开放给助手。

### 数据源完整性的验收定义

目录覆盖现代汉语、近代与古代汉语、学习者、口语与方言、平行翻译、英语及其他语言、学术、新闻网页、文学、词典与标注树库。每类列出代表性发布方、子库、官方入口、可取得内容、更新方式和接入路线；机构仓储另作发现入口。目录持续维护，不以未经核查的全球穷尽清单作为承诺。

每个条目分别显示已索引全文、已接入统计、已授权远程查询、待核实或仅目录。已同步规模只按平台成功发布的文档、字符、token、句对或音频时长计量；不相加上游宣传规模，也不把聚合仓储与其子库重复计数。目录本轮覆盖清单见来源全景，条目当前仍处规划或核验阶段。

### 首批必须形成可分析材料的来源

| 来源 | 首版数据 | 验收要求 |
| --- | --- | --- |
| Tatoeba | 中文与英文直接句对，作者和源句 ID | 真实版本检查、获取和发布；双向检索、关系增删、署名导出。 |
| Wikimedia | zhwiki 与 enwiki 正文；指定命名空间 | 月度 current 导出及校验；页面修订、结构清洗、字符/词位索引。 |
| Universal Dependencies | 至少一个许可核准树库；优先审查 Chinese-GSD | 正式 release 与 LICENSE 固定；CoNLL-U、POS/lemma 导入及句 ID 可回查。 |

S0 锁定实际包、许可、版本、样本清单与容量。任一必交来源不可取得时，记录阻塞并修订来源基线，不能用目录卡片替代通过。UN 平行语料为优先扩展，先完成下载可达性验证。现代新闻、文学与学习者等类别必须进入目录，未取得许可时不虚报已有全文。百科、例句和树库也不能标成平衡通用语料。

首批验证样本建议为 1 万至 5 万中英句对、每种语言 1 千至 5 千篇百科正文及一个核准树库；这是开发验证范围，不是承诺的正式库规模。试点发布必须明确完整包或固定抽样及其方法，抽样不能标为整库。

## 二 用户角色与研究场景

| 用户或场景 | 典型研究问题 | 应获得的成果 |
| --- | --- | --- |
| 语言学研究生 | 某个结构在不同年代、体裁或群体中如何使用。 | 可重复查询、频率与分布、例句、统计条件。 |
| 外语与应用语言学 | 不同熟练度学习者如何使用词汇、搭配或语法。 | 学习者子库、错误标注、组间比较及来源。 |
| 翻译研究 | 不同译者如何处理术语、句式或文化表达。 | 平行语料、译法比较、对齐和术语记录。 |
| 文学与数字人文 | 人物、叙事主题和表达方式如何跨文本变化。 | 文本标注、检索与可视化、可核对的材料集合。 |
| 话语与传播研究 | 不同媒体或机构如何表达某个议题。 | 来源分层、时间线、话语标签与抽样证据。 |
| 口语与多模态研究 | 话轮、停顿、手势和言语如何共同组织互动。 | 时间轴、说话人、多层标注和可回放片段。 |

### 个人与课题组

个人项目默认仅本人可见，资料存储在部署方服务器。加入课题组后，可授权成员查看选定项目、语料和结果。导师批注研究结果，不默认取得学生全部私人项目。首版不提供桌面壳或离线数据同步。

### 研究任务作为组织单位

一个项目可以包含多个研究问题。每个问题关联材料范围、纳入与排除标准、分析方案、执行记录和结果。检索条件、人工标注方案、对齐关系和图表都可以复用，但复用时保留原来源与版本。

### 成功的判断

研究者可以独立完成研究操作，并向导师解释每个关键数字和例句的来历。另一名有权限的研究者能用同一语料快照和配置复查计算；模型解释可以重新生成，但保存的原始输出与人工修改不会丢失。

## 知名语料库对标与首版验收

对标研究能力与数据组织方法，在我们获得授权的材料上实现。CCL、BCC、BNC、COCA 原库的规模、代表性和授权不因功能对标自动获得。下表官方资料核查于 2026 年 10 月 15 日；CCL 新站与可读官方手册的证据分别注明。

| 对标 | 有官方依据的能力 | 本平台首版验收 |
| --- | --- | --- |
| [CCL 2026](https://ccl.pku.edu.cn/news/535/detail) | 现代通用/专项/网络；古代断代/四库/佛道/丛书；中介语及订正材料。 | M01 M05：目录多维分类，按年代体裁筛选；缺失字段单列。 |
| [CCL 官方手册](https://corpus.pku.edu.cn/CCLCorpus_User_Guide.html) | 字距、布尔、KWIC、排序、上下文与结果导出；新站全部能力未实测。 | M06 M07 M12：字距/词距分别定义，命中可展开原文，结果可下载。 |
| [BCC](https://bcc.blcu.edu.cn/help.html) | 频道筛选、上下文、二次筛选、词形频次、历时与双查询比较。 | M07 M08 M09：频次图点选后回到同范围例句；年分母与缺失分开。 |

| [BNC 与 BNC2014](https://cass.lancs.ac.uk/bnc2014/) | 固定参考材料、口语/书面语、群体和时期研究。 | M05 M09：保存采样与构成，固定来源版本，比较组不混淆。 |

CCL 分类是时期、体裁、领域、产出者等多个维度的组合，不机械变成互斥文件夹。学习者原文与订正文本、译文与原文均以明确关系建模；首版保存关系，复杂偏误研究在 B 阶段扩展。

功能验收使用固定、可授权测试材料和独立预期结果；不得要求与 CCL/BCC 网站全库频次一致。只有数据版本、样本范围、处理方式与查询语义一致时，结果才具有直接可比条件。

### 功能集成的边界

常用研究流程在工作台内完成；成熟专业工具通过文件、受控插件或服务接口连接。声学实验、特定标注格式与学校现有工具需要互通，不能仅提供一个外部链接就计为已经覆盖完整操作。

### 资源接入的四种能力

来源登记分别记录目录发现、远程检索、全文分析和成果导出。部分来源可能只提供元数据，部分只允许校内使用。跨来源结果保留原有统计口径；没有统一全文和相同处理规则时，不相加为一个“全网词频”。

资源目录可持续纳入 BCC、CCL、BNC、COCA、OPUS、UD 树库、学术元数据与机构自建库。除已实际完成接入验证的资源外，一律显示为待评估或目录入口；不预先承诺全部内容可下载、可外发给模型或可再分发。

## 五 研究项目的完整流程

| 步骤 | 用户和系统共同完成的工作 | 保存的研究记录 |
| --- | --- | --- |
| 提出问题 | 明确研究对象、比较维度和需要检验的现象。AI 可帮助把宽泛问题拆成可操作任务。 | 研究问题与分析方案。 |
| 设计语料 | 确定来源、时间、语言、体裁、纳入排除规则、样本结构和对照组。 | 语料设计与抽样方案。 |
| 接入整理 | 导入或连接来源，提取文本，去重、清洗、脱敏并检查质量。 | 原件、处理版本与失败清单。 |
| 标注建库 | 分词、词形、词性与句法处理；建立人工标签或双语关系。 | 标注层、模型版本与复核状态。 |
| 检索分析 | 执行精确查询、词汇统计、搭配、分布与组间比较。 | 查询、统计口径和完整结果。 |
| 检查解释 | 返回原文核查，检查样本偏差和异常结果。AI 提出解释与后续分析建议。 | 证据清单、解释与待验证假设。 |
| 讨论修正 | 研究者和导师批注，修正标签、范围或参数并生成新结果。 | 修改历史与结果差异。 |
| 导出复现 | 导出研究表图、方法记录、数据包及可执行的分析配置。 | 成果快照与复现清单。 |

### 工作不会只沿一个方向进行

研究者可以从结果返回材料或分析条件。修改产生新的版本和任务分支，不覆盖已引用的结果。流程中已完成的服务端计算保留；联网模型失败、等待导师复核或外部资源暂时不可用，不应使整个项目归零。

### 一份可以讲清楚的研究记录

每个结论应至少能回答：材料来自哪里、选择了哪些样本、执行了什么查询、用了何种统计方法、哪些例句支持解释、谁修改或确认过结果。研究记录由操作过程自动积累，用户可以编辑说明。

## 六 语料设计与资料接入

### 在建库前定义研究范围

语料方案支持时间、地区、体裁、领域、媒介、作者或说话人群体、学习者水平及译者等元数据。字段可以自定义类型、枚举和必填条件。敏感身份字段与研究用匿名编号分开保存，未知信息不由 AI 自动填成事实。

支持全量纳入、随机抽样、分层抽样、样本量上限和配额；保存随机种子、排除理由和覆盖分布。比较组可检测重叠及规模差异，既支持独立样本，也支持有明确配对关系的研究设计。

| 输入类型 | 接入与质量要求 |
| --- | --- |
| 文本文档 | TXT、DOCX、文字 PDF、HTML、EPUB。保留章节、段落、脚注等结构，并识别阅读顺序异常。 |
| 结构化数据 | CSV、XLSX、JSONL、XML、TEI、CoNLL-U。提供字段映射、编码检测和格式校验。 |
| 双语材料 | 原文译文文件、双语表、TMX、XLIFF 与术语交换数据。保留语言、关系和状态。 |
| 音视频与字幕 | 音频、视频、SRT、VTT、EAF、TextGrid。保留时码、说话人及媒体关联。 |
| 扫描与图像 | OCR 提取文字并保留页图及坐标；低质量识别片段进入待复核。 |
| 外部连接 | 授权 API、机构存储和网页采集任务。逐源约定访问频率、允许字段、缓存与更新规则。 |

### 清洗与来源追踪

系统保存原件摘要、来源、获取时间和处理记录。页眉删除、断行修复、乱码替换、简繁转换与匿名化作为可查看的处理步骤。原文和分析文本分开保存，字符、页段或时间坐标之间保留映射。

完全重复可复用正文，保留各来源记录；近似重复由用户确认。导入界面显示成功、待检查、失败、重复和未处理数量。更新任务区分新增、变更、撤回与获取失败，获取失败不解释为来源已无内容。

## 七 语言处理与研究标注

### 可配置的语言处理流水线

按文档或片段识别语言，选择对应的分句、分词、词形还原、词性、命名实体和句法工具。中文、英文作为首批完整测试语言；其他语言通过能力矩阵说明已验证的处理步骤，避免把可导入等同于可可靠分析。

原始词形、词元、词性、结构属性和处理置信度分开保存。自定义词典、停用词表、标签集与规则有独立版本；模型升级后生成新的标注层，不直接替换人工确认层。

### 人工标注与预标注

| 标注能力 | 操作与数据规则 |
| --- | --- |
| 层与标签方案 | 支持文档、句段、连续或不连续跨度、关系、依存及时间轴层；标签定义和示例随方案保存。 |
| 手工编辑 | 支持选段、批量标注、标签快捷键、搜索替换、备注、撤销和变更对比。 |
| 机器预标注 | 模型和规则只写建议层。用户可按不确定性、规则冲突或随机样本组织复核。 |
| 多人标注 | 分配任务，支持双人独立标注、盲审、差异对比、裁决与锁定。 |
| 一致性评估 | 按标签类型选择一致性指标，记录样本和计算单位；类别标注与跨度匹配使用不同评价方法。 |
| 学习者与话语 | 支持错误类型、修正建议、语义角色、修辞功能、立场等自定义层；推断标签不能伪装为原文事实。 |

### 复核与后续分析

正式分析可明确选择原始层、机器建议层或人工确认层，结果中标明使用状态。标签方案改变时提供迁移预览和受影响条目，不能静默把旧标签解释为新含义。裁决后的集合可以形成独立评测集。

AI 训练或自动标注优化只使用另行允许的数据；测试集与用于调整规则的样本分开。持续记录每个语言、体裁和标签类别的错误，避免一个总准确率掩盖小类别失效。标注协作参考 INCEpTION 的能力范围。[S08]

## 八 检索与语料查询

| 检索方式 | 研究用途与规则 |
| --- | --- |
| 文字与词项 | 连续文字、完整词、词元、词组、大小写、简繁及重叠匹配开关；原文与归一化查询可区分。 |
| 正则与组合 | 支持正则、通配、布尔组合、排除项、邻近距离和有序或无序匹配；限制运行时间与结果规模。 |
| 属性与结构 | 按词性、实体、标签、依存关系、句段或章节约束查询；仅对具有相应标注的语料启用。 |
| 查询语言 | 提供可视化构建器与 CQL 风格表达式；公布支持的语法子集和版本，保存解析后的查询结构。[S05] |
| 元数据筛选 | 语言、时间、体裁、作者、地区、来源、学习者组别等字段组合筛选，显示筛选前后规模。 |
| 双语与跨模态 | 在原译文之间跳转，联动对齐关系；从转写命中跳到音视频片段。 |
| 语义与混合 | 语义检索和关键词混合排序用于找相关材料；明确显示相关性排序，不作为全库频次结果。 |

### 结果页

KWIC 即关键词居中上下文视图，支持左右多级排序、展开句段、查看全文、去除重复例句、随机抽样、手工收藏和导出。分布视图显示命中在文本中的位置；结果可按文档、标签或元数据聚合。

首版 AND/NOT 采用明确主查询锚点，同句条件只过滤主查询；OR 按跨度取并集，纯 NOT 不开放。命中数、句数、文档数分别展示。完整计数未结束时总数为空，不能把当前页当全库结果；点击命中打开被查询的固定版本。

### 保存与复用

查询可以命名、组合、共享并作为后续分析输入。自然语言查询显示可读条件与执行范围，参数和范围明确时直接运行；歧义会影响结果时再澄清。查询语法、属性和处理规模由业务服务校验，小样本预览按需使用，不增加逐次确认。

复杂正则或查询计划达到限制时可转后台任务、收窄范围或终止，不静默截断后仍标为完整结果。若外部来源只返回有限命中，保留其上限和统计口径。

## 九 词汇统计与语料比较

### 基础统计

词表按词形、词元、词性或用户标签聚合，展示原始频次、标准化频率、文档频次和有效文档数。每百万词频率的分母为当前范围内明确规则计算的有效词数；中文字符频率另设模式，不能与每百万词混用。

标点、数字、大小写、词形归并、停用词和重复文档策略都写入参数。停用词默认只过滤展示，不改变统计分母和上下文距离；如果确需排除正文或重新定义分母，建立新的分析配置。

| 能力 | 配置与输出 |
| --- | --- |
| 词簇与词汇束 | 连续 N 元词组、围绕节点词的词簇、带槽位模式和非连续词组；记录词序、允许间距及边界。 |
| 关键词比较 | 指定目标与参照语料，输出正负关键词、原始计数、频率差、效应量与检验结果。 |
| 方法选择 | 支持 log likelihood、卡方等已验证方法；阈值、多重比较及稀疏计数处理明确呈现，不能把不同分数统一叫显著性。 |
| 词汇多样性 | 提供 TTR、MATTR 等指标，记录文本长度、窗口与分词方式；不足样本返回原因。 |
| 分布与离散度 | 显示词项覆盖的文档、文本位置及跨子库分布，提供 Range、离散度等可解释指标。 |
| 批量与矩阵 | 同一分析配置批量运行多个词项、子语料或时间段，输出词项与文档的矩阵。 |

### 比较的前置检查

运行前展示两组资料的语言、年代、体裁、文档数、总词数、重叠比例和缺失字段。独立组与配对组使用不同分析配置；同一作者或说话人的多段材料不自动视为相互独立的样本。

标准化频率解决规模口径，不能自动消除题材、作者和年代差异。系统提供描述性结果和可检查的方法选择；样本条件不足时保留提示，不强行给出显著结论。

### 验证标准

每种指标建立公式说明、边界条件、实现版本和独立参考用例。零分母、零计数、最小频次及多重比较规则写入方法记录。关键词与效应量的功能参考 AntConc，离散度与批量任务参考 LancsBox。[S01][S04]

## 十 搭配语法关系与探索分析

### 窗口搭配

用户设置左窗、右窗、单位、是否跨句、最低共现次数与文档数。共现表同时显示原始次数、覆盖文档和关联分数；窗口中每个候选位置如何计数由算法规范固定，不能因界面分页或抽样而变化。

提供 logDice、MI、t-score 等可选择指标，展示各自用途与限制。分数相同不表示语义相同，较高分数也不自动说明研究意义。指标实现以确认的公式和计数条件为准，建立与参考用例的一致性测试。[S03][S06][S18]

### 语法搭配与词语比较

| 能力 | 研究者的操作 | 输出 |
| --- | --- | --- |
| 语法关系搭配 | 按主谓、动宾、修饰等关系查看词语连接，选择已验证的词性或句法层。 | 关系分类、分数、数量及原句。 |
| 词语差异 | 比较同义词、近义词或两组语料中同一词的搭配。 | 共有与差异搭配、计数与例句。 |
| 搭配网络 | 选择节点、关系、阈值和布局；点击边回到对应证据。 | 可交互网络与可导出的底层边表。 |
| 时间与位置 | 按时间、文档位置或元数据分组，选择统一单位。 | 趋势线、离散分布及样本规模。 |
| 探索模型 | 主题、聚类、相似文本、对应分析或降维；保存特征与随机条件。 | 探索图、组内材料和待验证解释。 |

### 专业结果与探索结果分开

词汇素描依赖语言标注和语法关系规则，每种语言分别验收。没有满足要求的标注时，该功能说明缺少条件并引导处理，不以普通窗口共现冒充语法搭配。

主题和聚类用于发现线索。主题名称可以由 AI 建议，但保留原始词项、文档组成和人工命名。不同运行产生的分组不能直接当作稳定事实；相关性或聚类关系不能写成因果关系。

网络、趋势和散点图的筛选条件与底层结果绑定；图表上的任何选中范围都能还原到数据行与原文。相关探索能力参考 LancsBox 与 Voyant。[S04][S07]

## 十一 双语对齐与翻译研究

### 对齐对象与编辑

首版支持已处理共享材料或私有材料的一对一句级自动对齐候选，以及新增、替换、拒绝和确认。保存原文端点、方法版本、匹配分数和未配对清单，不强行配对。后续扩展文档与段落配对、一对多、多对多、空对应、调序及合并拆分编辑；复杂关系在首版只读。

共享来源关系保持不可变。项目覆盖层绑定固定研究快照及修订；基础来源引用可选，纯私有材料无需虚构挂载。机器候选按指令保存为建议；用户明确核对的条目才记人工确认。修改生成新修订，分析固定覆盖层版本，不改变其他项目或旧结果；两侧唯一句数、关系数与展示行分别计数。

| 研究能力 | 完整设计 |
| --- | --- |
| 平行检索 | 原文查询联动译文，译文查询回到原文；保留语言、原译关系及上下文。 |
| 多译本对照 | 同一原文关联多个译本，按译者、版本或年代比较；不要求各译本句数一致。 |
| 翻译记忆 | 已确认片段形成可复用翻译单元，提供完全或模糊匹配；与原始对齐关系分开管理。 |
| 术语研究 | 单语及双语候选、概念、首选译法、变体、禁用词、语境、出处与确认记录。 |
| 译文质量研究 | 自定义错误类型和翻译策略标签，支持人工评估、双人复核及汇总。 |
| 学习者语料 | 关联匿名学习者元数据、错误跨度、修正层与任务信息；原始表达不被修订覆盖。 |

### 自动翻译的角色

AI 可以提出译法和解释，但机器生成内容保存在派生层。真实译文、学生修改和机器建议在检索与导出中可以分别筛选。自动评价分数仅作为辅助信号，必须说明模型、量表与适用样本。

### 交换与导出

双语表可按状态导出；正式翻译记忆默认只包含两侧非空且人工确认的条目。TMX 输出保留语言与必要标记，多对多关系使用明确合并规则；不兼容结构给出转换清单。对齐、记忆和术语作为不同对象，参考 Trados 与 TMX 规范。[S11][S12]

## 十二 口语音视频与多模态研究

### 围绕时间轴组织证据

项目保存媒体文件、采样信息、时间基准和派生转写。播放器、波形、转写和标注层同步定位，支持片段循环播放、速度调整、时间缩放和多轨道对照。搜索命中可以直接播放对应片段。

| 模块 | 完整能力与边界 |
| --- | --- |
| 转写与说话人 | 语音识别、说话人分离、词句时间对齐分别保存结果和置信信息；说话人编号不自动映射为真实身份。 |
| 转写校对 | 保留重复、口误、停顿、重叠发言与非言语声音；润色稿另建层，不覆盖原始研究转写。 |
| 多层标注 | 词句、翻译、语调、手势、目光和研究者定义的层可独立或相互关联，支持重叠区间。 |
| 声学分析 | 基础波形与频谱，以及可配置的基频、强度、共振峰等测量；返回片段、参数与工具版本。 |
| 跨层检索 | 组合文本、说话人、时间范围和标签条件，检查语言与非语言行为的共同出现。 |
| 专业互通 | 支持 EAF 与 TextGrid 的已声明子集、媒体片段导出及 Praat 适配任务；复杂结构检测转换损失。 |

### AI 与人工复核

AI 负责初步转写、对齐和预标注，研究者校对文字、边界及说话人归属。手势、情绪等识别按专项实验模块处理，提供独立验证，不作为所有材料均可靠的默认能力。

声学值来自明确的分析工具，不由语言模型估计。模型与算法配置按语言、口音、录音质量和说话人条件分别测试，展示每组错误情况。多模态建模参考 ELAN，专业声学处理参考 Praat。[S09][S10]

### 长媒体处理

媒体任务按片段建立检查点，保留原始时间映射。分片后合并结果时检查重叠、缺失和时间偏移；取消后不得继续写入新结果。服务端承担长任务，浏览器继续查看已完成部分，关闭页面不终止作业。

## 十三 AI 能力的完整设计

| AI 能力 | 实际完成的工作 | 用户可检查的依据 |
| --- | --- | --- |
| 研究方案助手 | 细化研究问题，建议材料分组、抽样、变量和可执行方法。 | 方案、假设、所需材料和方法来源。 |

| 标注助手 | 按标签方案预标注、提示不确定项，推荐复核顺序。 | 标签定义、证据、建议与人工修正。 |
| 双语助手 | 生成一对一对齐候选、按指令保存修订并执行比较；术语等后续上线。 | 左右原文、方法版本、候选及确认依据。 |
| 音视频助手 | 生成转写、说话人轨道与时间对齐候选。 | 原始媒体、时码和人工校对层。 |
| 统计解释助手 | 调用统计工具、下钻例句并解释真实结果。 | 结构化数值、单位、分母与证据。 |
| 来源问答助手 | 在指定语料或参考文献范围内回答，整理支持及反对证据。 | 具体片段、来源版本与不足证据。 |
| 研究记录助手 | 汇集方法、图表、引用和操作过程，生成可编辑记录。 | 各段文字关联的数据或材料。 |
| 脚本与图表助手 | 生成受控分析脚本和绘图配置，经检查后在隔离环境运行。 | 脚本、输入、运行日志与可复查输出。 |

### 研究助手的业务覆盖

来源、项目、材料、快照、检索、统计、对齐、笔记、任务、导出和项目备份恢复均可通过助手执行；成员、模型策略、目录治理、全局同步及撤回按现有角色权限提供。项目恢复先展示影响再按授权执行；整机备份演练属于运维。登录验证、文件选择和下载由网页协作完成。

“将这两份材料对齐，再比较译文并保存结果”可形成连续任务：解析材料、固定快照、生成候选、按指令保存项目关系、切换到新修订范围、执行分析和导出。候选保存不等于人工确认；只有用户明确核对的条目才登记确认依据。

工具覆盖属于各模块交付条件。已上线动作缺少助手工具即未完成集成；规划中的 OCR、复杂标注、术语、多模态等按既定阶段上线。注册表区分业务动作、网页交互和运维过程，不向模型开放服务器 shell、数据库管理或密钥。

具体动作、工具名、输入输出和验收依据统一维护在 assistant-capabilities.md 及对应《研究助手业务能力与工具契约》，本规划保留 M01 至 M14 和 F001 至 F096 的分期。

### AI 的输出分层

原始证据、程序计算、机器建议、研究者解释和人工确认分开保存。助手可按明确用户指令提交业务修订，保留旧版本及操作来源；模型建议不能冒充人工确认。原件和已发布快照不原地改写。每次模型请求检查数据范围与外发权限，缺少证据时不补造事实。

参考文献库与研究语料分开：文献可用于说明已有方法，语料用于产生本项目数据，不能把论文中的结论当作自己的统计结果。来源问答与文献流程参考 Google 与 Elicit 的公开能力。[S15][S16]

## 十四 Pi Agent 的执行流程与约束

### 从问题到可执行任务

研究助手采用 Pi SDK，由 Node.js/TypeScript 宿主组织步骤并通过 FastAPI 调用业务能力。当前用户有权使用的全部已上线业务动作都提供类型化工具；助手能读取、创建、修改、执行、取消、重试、保存和导出。手动入口与工具共用业务服务，Celery 完成同步、处理、对齐、统计等后台计算。

| 执行环节 | 强制规则 |
| --- | --- |
| 计划校验 | 工具名称、参数、依赖、数据版本和权限必须通过结构化校验；不能从原文中的指令触发操作。 |
| 执行与检查点 | Pi 保存会话上下文，业务账本保存运行、工具与成果。固定调用 ID；恢复先查已有结果，不能重放写入。 |
| 操作授权 | 目标明确且已授权的可逆操作直接执行；破坏性操作核对具体影响及既有授权，缺失时再确认。人工确认须有用户核对依据。 |
| 模型调用 | 记录提供方、模型标识、提示模板、输入摘要、输出与采纳情况；记录实际用量并设运行上限。 |
| 暂停与恢复 | 会话单写；等待后台任务时不空转。取消拒绝新工具，已发布成果保留；来源撤回暂停受影响会话。 |
| 资源加载 | 只加载审核的研究工具、Skills 和提示词。首版不开放通用脚本、bash 或第三方扩展安装。 |

### 证据和数字的绑定

统计工具返回带标识的数据表，报告中的关键数字从表中插入。生成的事实性论断关联结果行或原文片段；引用定位、论断覆盖和证据支持度分别检查。引用存在不等于论断正确，支持与反对例句都可进入证据清单。

### 可复现的边界

确定性处理使用固定输入、算法、词典和参数，按声明的精度复查。生成模型的原始输出完整保留；再次请求同一模型也可能不同，因此将重新生成视为新结果。比较新旧输出并保留人工修改，不宣称 AI 文本必然逐字复现。

Pi 沿用模型适配层；学校可配置校内或远程模型。来源撤回后停止受影响会话，旧正文与摘要不再外发。项目、材料成员、快照或对齐修订改变时，宿主用结构化后续任务新建净化会话并重读材料；同一范围内的新查询、分析、证据和笔记继续当前会话。完整工具与接续契约见《研究助手业务能力与工具契约》。

## 十五 研究记录可视化与成果导出

### 研究记录工作区

研究问题、语料方案、操作记录、结果、图表、例句、文献和导师意见以研究任务关联。支持将某次分析结果固定为成果快照，添加解释和限制说明，再引用到研究记录中。修改记录的文字不会改变底层数据。

### 图表能力

提供词频与关键词图、时间趋势、分布图、组间比较、交叉表、搭配网络、词树、主题及降维视图。每张图绑定数据和参数，可从图回到结果表。保存图形配置、轴单位与筛选条件，支持矢量或高分辨率导出。

| 输出 | 内容与互通要求 |
| --- | --- |
| 数据表 | CSV、TSV、XLSX、JSONL；用户选择字段，保留单位、来源和必要状态。 |
| 研究报告 | DOCX、PDF 或 Markdown；包含问题、语料、方法、结果、证据和人工解释。 |
| 专业语料 | TEI、CoNLL-U、TMX、术语交换数据、EAF 和 TextGrid 按已验证子集导出。 |
| 引文与文献 | BibTeX、RIS 等书目信息和可追踪的来源定位；缺失书目字段不得自动编造。 |
| 图形 | SVG、PDF、PNG 等格式；同时导出生成图表的数据和配置。 |
| 项目包 | 原始材料或允许分享的替代引用、版本、标注、分析配置、结果和完整性清单。 |

### 可复查与可分享

对外成果给出文档名称及页、段或时间定位；应用内链接是补充，不能成为唯一核查路径。发布前检查来源授权、身份信息和人工确认状态。不能分享原文时，可以输出允许的统计和引用标识，并说明复现所需访问条件。

表格标题使用宋体，XLSX 不添加背景填充。Word 标题使用宋体，默认没有无关页眉页脚、装饰小字和自动附加品牌。必要的方法、参数和来源说明属于正文，以正常字号显示。

| 导航入口 | 主要工作区 | 常用动作 |
| --- | --- | --- |
| 研究项目 | 研究问题、任务、最近成果和项目设置。 | 创建问题、开始任务、恢复进度。 |
| 语料与来源 | 平台来源目录、可分析语料、私有材料、子库和快照。 | 选择、订阅更新、查看质量、冻结研究范围。 |
| 同步任务中心 | 源版本、最近检查、发布记录、失败与撤回。 | 管理员调度、重试、停用和回退；学生查看进度。 |
| 检索 | KWIC、原文、查询编辑器和筛选。 | 查询、排序、抽样、收藏证据。 |
| 统计分析 | 词表、关键词、词组、搭配、分布和比较。 | 配置、运行、图表、保存结果。 |
| 标注 | 标签方案、待标注材料、分歧和裁决。 | 手工标注、接受建议、复核。 |

| 研究记录 | 结果、证据、文献、说明和导师批注。 | 组织成果、引用、导出、分享。 |

### 研究助手主工作台

研究助手为项目默认入口，主区集中会话、任务过程和输入，辅助区呈现材料、结果、证据与成果。工具返回可定位的正式结果，支持跳转专业页面继续编辑；手动操作可回到同一任务，固定相同版本。范围变化按会话接续规则处理。当前原型仍使用示例模拟，真实 Pi 和后端待实施。

### 基础模式和专业模式

基础模式提供默认参数与示例，研究者可逐步展开专业设置。专业模式展示查询语言、分词与句法层、统计指标和完整参数。两种模式使用同一数据与算法，切换不改变已有计算结果。

首屏明确当前项目、语料快照与选择范围。修改条件时显示尚未重新计算；长任务显示进度与取消，空结果区分无匹配、无权限、语料未处理和任务失败。快捷键、批量操作、撤销与原文定位保持一致。

## 十七 课题组协作与权限

### 角色与工作范围

| 角色 | 默认职责 | 边界 |
| --- | --- | --- |
| 项目负责人 | 设置项目、成员、材料范围与成果发布。 | 不能改变外部来源实际授予的处理范围。 |
| 研究成员 | 使用授权语料、运行分析、创建标注和结果。 | 仅访问被授权的项目及资料层。 |
| 标注成员 | 完成分配的材料与标注方案。 | 可限制下载原件及访问身份映射表。 |
| 复核者或导师 | 批注、检查结果、裁决分歧、确认成果。 | 共享范围由项目设置，私人项目不自动开放。 |
| 学校管理员 | 部署、账号、运行资源、备份与服务状态。 | 管理权限和查看研究内容的权限分别控制。 |

### 协作操作

支持任务分配、评论、提及、审核记录、结果快照分享和项目模板。多人编辑标注或对齐时采用对象锁或版本校验，冲突需明确解决；原文和已发布快照不可在后台被另一名成员悄悄改写。

网页编辑使用版本校验，涉及同一标签、对齐或正文的冲突需明确处理。断网时保留符合项目策略的编辑草稿，并标为未提交；重连后重新校验权限和版本，不承诺离线完整分析。

### 权限随操作检查

查询、原文预览、模型外发、导出、分享、下载和缓存读取分别检查权限。执行任务的身份和当前授权保持绑定，队列中的任务在真正运行前再次校验；撤销授权后停止新处理，并使受控缓存与共享入口失效。

对研究参与者身份信息，默认使用匿名编号并单独存储映射。共享或导出先检查字段范围；语音和视频中的身份内容无法仅靠删姓名完全匿名，应由项目的材料处理规则决定访问范围。

### 备份与恢复

个人项目提供可校验备份和恢复，学校服务端提供定期备份、恢复演练与审计。已经下载到应用外的文件无法技术性撤回；系统展示发布和导出记录，便于项目负责人追踪。

## 十八 技术架构与部署方式

### 统一内核与网页部署

采用 React/TypeScript 网页、FastAPI 业务服务、Node.js/Pi Agent 宿主、PostgreSQL、对象存储与 Celery 任务进程。阶段 A 实现来源注册和同步、共享语料快照、项目私有快照、精确检索、基础分析及 AI；阶段 C 扩展机构管理和协作调度。个人项目是权限边界，不表示数据保存在个人电脑。

| 层次 | 职责 | 关键约束 |
| --- | --- | --- |
| 交互层 | 研究助手主工作台、专业编辑器、图表和任务中心。 | 通过统一业务接口展示真实结果。 |
| 项目与策略层 | 项目、快照、角色、来源能力、数据处理规则。 | 每次读写、外发及导出均检查范围。 |
| 专业工具层 | 解析、清洗、检索、统计、标注、对齐、声学和导出。 | 工具独立可调用，可通过参考数据验收。 |
| 任务与 Agent 层 | Node/Pi 管模型循环；Celery 管同步、索引、分析和导出。 | 通过 FastAPI 校验权限与发布结果，不建第二套 Agent 循环。 |
| 数据层 | 原件、版本、标注、元数据、索引、向量和研究记录。 | 区分权威数据与可重建索引。 |
| 互通层 | 外部来源、模型、专业软件、格式适配和插件。 | 声明能力、版本与转换损失。 |

### 建议选型与验证

PostgreSQL 保存来源、项目、权限、版本和任务；对象存储保存原件、正文、索引与成果。CWB/CQP 作为词位检索候选，中文任意字符串另设字符检索路径。精确查询与语义召回分开，完整契约及替代条件见网页技术设计。[S05]

客户端、解析器、标注模型和索引引擎通过接口隔离。先用目标样本验证原文映射、复杂查询及数据规模，再冻结具体版本与依赖；不因选用某个 Agent 框架而改变研究数据模型。

### 运行方式

任务账本与队列运行在服务器，关闭浏览器不影响已提交任务。业务任务与 Pi 运行分别限流和保存状态；关闭页面仅断开订阅。同一工具调用重试复用已有任务，取消不撤销已发布成果。

## 十九 核心数据模型与版本

| 对象 | 主要内容 | 关系与版本规则 |
| --- | --- | --- |
| 项目与研究问题 | 成员、研究问题、方案和工作区。 | 关联多个语料快照及分析分支。 |
| 来源与原始资产 | 来源地址、权利记录、文件摘要、媒体信息。 | 一份正文可对应多个来源记录。 |
| 文档版本与片段 | 不可变正文、页段时码、原文位置映射。 | 句段标识在版本内稳定，改文产生新版本。 |
| 标注层与方案 | 词法句法、研究标签、机器建议与人工记录。 | 方案及模型单独版本化，支持并列层。 |
| 对齐与术语对象 | 左右片段关系、翻译单元、术语概念与译法。 | 确认绑定具体输入版本，关系变化重新复核。 |
| 语料快照 | 文档版本列表、分组、抽样和排除策略。 | 固定研究范围，不自动加入新文件。 |
| 分析运行与结果 | 工具、参数、版本、数据表、图形和解释。 | 结果不可变，编辑解释另存修订。 |
| 证据与发布记录 | 论断、结果行、原文片段、引文和共享范围。 | 可追溯到原版本，记录失效与导出。 |

### 影响传播

修改正文、分句、词典、标注方案或处理模型时，系统计算受影响的对齐、统计和引用。新版本显示需要重算或复核；旧成果仍保留其当时输入和状态。变更权限不会修改历史授权记录，但当前访问受最新授权约束。

### 索引与持久记录

原件、正文版本、人工修订和结果清单是权威记录。完整且兼容的来源索引可复用，子集和共享私有混合快照建立项目索引；复用不能跳过权限。索引、向量和缓存可重建，分别记录版本。备份恢复后检查对象完整性与映射，不依赖原电脑绝对路径。

### 删除的含义

移出当前范围、删除一个版本和彻底删除资产是不同操作。彻底删除先列出关联结果，确认后清理系统管理的副本与含原文派生内容，旧记录转为无正文的失效状态。备份保留与清理周期由学校策略明确约定，不承诺即时擦除应用外副本。

## 二十 接口格式与扩展机制

### 统一工具接口

全部已上线业务动作使用结构化接口，并登记业务能力、输入输出、权限、范围影响、版本和结果入口。工具只能调用明确的后端命令或查询，不提供任意 HTTP、SQL、shell 或凭据访问。输入身份由服务端注入；输出包括真实状态、结果或任务引用、版本、计数和证据。

任务提交返回任务标识，可查询进度、取消或从检查点恢复。权限检查由服务端策略模块完成，不能仅由模型提示词保证。写入使用事务或可恢复提交，结果文件与元数据不会各成功一半而仍报告完成。

| 交换对象 | 格式或接口 | 必须验证 |
| --- | --- | --- |
| 文本和结构 | TXT、DOCX、PDF、HTML、EPUB、TEI。 | 正文顺序、章节、语言与页段定位。 |
| 词法句法 | CoNLL-U 等结构化标注。[S14] | 词形、词元、标签、依存、多词项及空节点。 |
| 双语和术语 | TMX、XLIFF、术语交换格式。[S12] | 语言、内联标记、多句合并及元数据。 |
| 多模态 | EAF、TextGrid、SRT、VTT。 | 时间单位、层关系、重叠区间与媒体引用。 |
| 研究与编程 | CSV、JSONL、配置文件及受控 Python 或 R 接口。 | 列类型、单位、缺失值、参数和可重复执行。 |
| 项目归档 | 清单、版本数据、原件或授权引用、成果与校验。 | 在另一环境恢复并解释不完整依赖。 |

### 兼容级别

每个适配器说明支持读取、写入、往返及哪些字段保留。采用固定参考文件做导入、导出、再导入比较；无法映射的属性和内容必须列明。未知结构可保留原始载荷，但不能伪装为已完整理解。

### 扩展包

新增语言、格式、统计方法和外部数据源均通过版本化扩展包注册。扩展声明输入输出、运行权限、依赖和验证样本。更新前在测试项目运行，允许回退；第三方脚本与模型不能默认获得全部项目和网络权限。

## 二十一 运行质量与性能目标

以下为工程验收建议，开发前需固定设备、样本、查询集合及测量方法。在固定服务器、语料版本和查询集上分别测量单用户与多用户性能；目标不是已测结果。

| 场景 | 基线条件 | 目标 |
| --- | --- | --- |

### 可观测与资源保护

记录任务耗时、失败率、索引状态、取消响应、模型请求量和外部接口限流。日志默认不记录原文与密钥。长任务设 CPU、内存、临时空间、请求次数与输出上限；资源耗尽时保留已完成的可恢复结果。

### 学校运行控制

学校可配置账号集成、网络出口、允许模型、数据保留和备份策略。跨项目检索、缓存、导出和模型请求进行越权测试；插件输入、文件解析和归档恢复纳入测试，避免把不可信材料当作可执行内容。

### 测试集和结果解释

用于调整提示、阈值和模型的样本，与最终验收样本分开。记录样本组成、软件版本和评价方法；任何总体分数同时提供分组结果。试点达标只说明在约定范围内可用，不将小样本结果外推到全部语种和体裁。

样本中发现的具体错误应修正，模型无法修正时通过人工复核或限制使用范围处理。功能发布同时交付已知限制、失败示例和检查方法，保存在正常产品说明中。
