# 方法章节

## 适用问题

- “帮我写方法部分。”
- “把刚才的统计整理成结果描述。”
- “我用到的统计方法应该引用哪些文献？”

## 步骤

1. 收集来源：本次对话中统计工具返回的 stat_id、检索用过的查询式与范围（含 aligned 译文条件）、用到的标注层或抽样层 layer_id。用户说“证据篮里的”时用 evidence=true。
2. 生成附录：methods_appendix，传 stat_ids、searches、layer_ids 或 evidence；style 默认 gbt7714，用户要 APA 时用 apa。
3. 把返回的 markdown 原样给用户，可以简述它包含哪些部分；不增删其中的数字、参数和文献。
4. 用户要结果描述草稿时：按统计逐项写“方法 + 范围 + 数值”的陈述句，数值照抄工具结果并带单位（每百万词、%、LL、logDice 等）；需要的数值本次对话中没有时，先调用对应工具，不凭记忆补。
5. 草稿中需要用户解释的位置写“〔解释由作者补充〕”，不替用户写解释和结论。

## 工具与参数

- methods_appendix：stat_ids、searches（query、scope、aligned）、layer_ids、evidence、style。
- 补数时用对应的统计工具（stats_*、sample_summary、annot_agreement）。

## 呈现

- 附录：Markdown 原文。
- 结果描述草稿：Markdown 段落，每个数字后括注来源统计名称，如“（关键词，UD 中文 对 新闻语料）”。
- 用户要保存时用 kb_save（写操作，需确认）。

## 口径与局限

- 附录记录语料规模与索引版本；语料重建索引后数字可能变化，提醒用户以附录中的版本为准。
- 抽样的 estimate 是估计值，草稿中写明“估计”。
- 统计显著不等于差异重要；草稿只陈述数值，不写“证明”“说明了”等结论性措辞。
- 文献条目只用附录返回的，不自行添加。
